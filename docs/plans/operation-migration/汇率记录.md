# 汇率记录 operation-management/rate/ → src/views/operation/Rate.vue

## 源页结构
- head-info 标题「汇率记录」+ app-panel
- 顶部单个「新增记录」文字按钮（无筛选区）
- 主表格 el-table（本币兑目标币对），分页 layout="total, prev, pager, next"
- 弹窗1：新增/编辑记录（600px），仅选本币+目标币
- 子表弹窗：records.vue 子组件（960px），点「汇率记录」列打开，内含生效日期表单 + 汇率明细表 + 分页（二级弹窗+子表）

## 筛选项
- 无搜索栏。源页没有任何筛选控件，仅一个「新增记录」按钮。

## 表格列
- 本币 prop=lcName
- 本币编码 prop=lcId
- 目标币 prop=fcName
- 目标币编码 prop=fcId
- 汇率记录 width=120，插槽按钮「汇率记录」，disabled=!$checkPermission(['exchangerateStatistics'])，点击 showDialogA
- 最新汇率 width=120 prop=rate
- 最后更新 width=200 prop=updateTime
- 操作 fixed=right width=180：编辑/删除

## 操作按钮
- 新增记录：v-permission="['exchangerateAdd']"，打开新增弹窗
- 汇率记录（列内）：$checkPermission(['exchangerateStatistics'])，打开 records 子弹窗
- 编辑：v-permission="['exchangerateUpdate']"
- 删除：v-permission="['exchangerateDel']"，$confirm「请确认是否删除该条数据?」/「温馨提示」

## 新增/编辑表单字段
主弹窗 form（label-width=100px）：
- 本币 prop=lcId：el-select（filterable clearable，@focus=getCurrencyList），选项 currencyList，label=`${name}-${sign}` value=id。校验：required change「请选择本币」
- 目标币种 prop=fcId：el-select（@focus=getCurrencyList），同上选项。校验：required change「请选择目标币种」
- 提交 saveExchange
records 子弹窗 theForm（inline，size=small）：
- 生效日期 prop=effective：el-date-picker type=date value-format="yyyy-MM-dd"。校验 required「请选择生效日期」
- 保留小数 decimals：el-input-number min=2 max=5 step=1 step-strictly
- 汇率 prop=rate：el-input-number min 依 decimals，:precision=decimals。校验 required「请输入汇率」
- 按钮：清空 / 新增或保存（依 theForm.id）

## 详情/次级弹窗/子页
- records.vue：标题「汇率记录（{lcName}兑{fcName}）」，生效日期录入表单 + 明细表（生效日期/汇率/操作：编辑、删除）+ 分页。删除同样 $confirm。init(id, lcName, fcName) 打开。关闭 emit('closing') 刷新主表。

## 目标页现状
- SearchBar 含「币种」「状态」两个下拉；ProTable 列：币种/汇率/汇率日期/状态(el-switch)/创建时间；Modal 表单：币种(select)/汇率(input-number precision=4)/汇率日期(date)/状态(radio)；rateApi + useListQuery/useCrudForm，rules 仅 currency required

## 差异
- 【结构性错配】源是「货币对（本币/目标币）」主表 + 汇率历史子表两级结构；目标是单表平铺。整页数据模型不一致。
- 需补列：lcName/lcId/fcName/fcId/rate/updateTime；「汇率记录」列及 records 子弹窗。
- 需补权限键：exchangerateAdd / exchangerateUpdate / exchangerateDel / exchangerateStatistics（目标全无）。
- 需补：新增/编辑弹窗 lcId/fcId 双币种；records 子组件校验；decimals 控制 precision。
- 目标虚构需删：币种/状态筛选、状态 el-switch 列、汇率日期字段、precision=4、CURRENCIES 枚举、搜索栏。
- 工作量：极大（含子组件重建 + mock 双表结构）。
