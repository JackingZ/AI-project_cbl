## 新增/编辑表单字段
ruleForm（label-width=100px，size=small）：
- 中文名称 prop=name：el-input show-word-limit maxlength=20，ref=firstInput 自动 focus。校验 required blur「中文名称不能为空」
- 英文名称 prop=alias：el-input maxlength=20。校验 required「英文名称不能为空」+ validator 禁中文(/[一-龥]/)「英文名称不能有中文」blur
- 货币编码 prop=id：el-input maxlength=3 show-word-limit，:disabled=isEdit。校验 required「货币编码不能为空」+ 长度=3「货币编码长度为3」+ 纯字母 /^[a-zA-Z]*$/「货币编码只能包含字母」blur
- 货币符号 prop=sign：el-input maxlength=3 show-word-limit。校验 required + 禁中文「货币符号不能是中文」blur
- 通用国家 prop=countryIds：只读 el-input(placeholder=`已选择(${countryIds.length})`) + append 搜索按钮打开穿梭框。校验 required blur「通用国家不能为空」
- 提交 addCurrency / saveCurrency

- 需补列：英文名称 alias、通用国家(countryNameFilter)；编码列 prop 应为 id 而非 ccode。
- 需补权限键：addCurrency / editCurrency / deleteCurrency。
- 需补表单：alias(+禁中文)、通用国家 countryIds(穿梭框)。
- 需补校验：alias 禁中文；id 长度=3 纯字母 + 编辑禁用；sign 禁中文；countryIds required。
- 需补：关联通用国家 el-transfer 弹窗 + getCountryList/saveRelate。
- 删除文案：「删除货币将导致无法继续使用，确定要删除吗？」
