# 岗位设置 operation-management/job-setup/index.vue → src/views/operation/JobSetup.vue

## 源页结构
- head-info「岗位设置」+ app-panel；顶部 el-row：左「新增岗位」按钮 + 右侧行内筛选（公司类型下拉 + 岗位名称输入 + 查询）；主表格 + 分页
- 弹窗：新增/编辑岗位（600px）

## 筛选项
- 公司类型 selectValue.type：el-select clearable placeholder「公司类型」width=120，SYSTEM=0/客户=1/代理商=2/供应商=3
- 岗位名称 selectValue.name：el-input clearable width=300，prepend 文字「岗位名称」，placeholder「请输入」
- 查询按钮：v-permission="['postsettingQuery']"，@click=queryAll(1)

## 表格列
- 岗位名称 prop=name
- 岗位类型 width=150，插槽 postFilter(row)（按 workList 匹配 postType→label）
- 公司类型 min-width=120，插槽 typeFilter(row)（type 逗号串→SYSTEM/客户/代理商/供应商）
- 服务大类 prop=subtypeName min-width=150 show-overflow-tooltip
- 添加时间 prop=createTime width=180
- 操作 width=120 fixed=right：编辑

## 操作按钮
- 新增岗位：v-permission="['postsettingAdd']"
- 查询：v-permission="['postsettingQuery']"
- 编辑：v-permission="['postsettingUpdate']"
- （源页无删除）

## 新增/编辑表单字段
form（label-width=120px，size=small）：
- 岗位名称 prop=name：el-input maxlength=20。校验 required blur「岗位名称不能为空」
- 企业类型 prop=type：el-select multiple collapse-tags filterable clearable，SYSTEM=0/客户=1/代理商=2/供应商=3，@change=onType(清空 subtypeId 重拉)。校验 required change「请选择企业类型」
- 服务大类 prop=subtypeId：el-select multiple collapse-tags filterable clearable，:disabled=!form.type，选项 subtypeList(name/id)。校验 required change「请选择服务大类」
- 岗位类别 prop=postType：el-select filterable clearable，@focus=getWorkList，选项 workList(label/value)。非必填 change
- 提交 addPost / editPost（type、subtypeId join ','，组装 subtypeName）

## 详情/次级弹窗/子页
- 无二级弹窗。依赖 getServiceTypeList(custType)、getWordsList(type='POST_TYPE1')

## 目标页现状
- SearchBar：岗位名称(input)/所属部门(select DEPTS)/状态(select)；列：岗位名称/编码(code)/所属部门(dept)/状态(switch)/创建时间；Modal：岗位名称/编码/所属部门(select)/状态(radio)；rules 仅 name required

## 差异
- 【结构性错配】源核心是「企业类型(多选)→服务大类(多选,联动)→岗位类别」；目标是「编码/部门/状态」，字段虚构。
- 需补列：岗位类型(postFilter)、公司类型(typeFilter)、服务大类(subtypeName)、添加时间。
- 需补筛选：公司类型下拉(0/1/2/3)、岗位名称(prepend)、查询 v-permission postsettingQuery。
- 需补权限键：postsettingAdd / postsettingQuery / postsettingUpdate。
- 需补表单：企业类型 type(multiple)、服务大类 subtypeId(multiple, disabled=!type, 联动 onType)、岗位类别 postType(@focus workList)。
- 需补校验：name required blur；type required change；subtypeId required change；postType 非必填。
- 需补联动：onType→getSubtypeList、getWorkList(POST_TYPE1)、typeFilter/postFilter。
- 虚构需删：所属部门 dept/DEPTS、编码 code、状态 switch/radio、状态筛选、删除按钮(源无)。
- 字段映射：name→name 保留；code/dept/status 无源对应。
- 工作量：大。
