# 机场港口 port-management/index.vue → src/views/operation/PortManagement.vue

## 源页结构
- 单页 head-info + app-panel。左上"新增港口"按钮，右上筛选。el-table + 分页。
- 新增/编辑同一 el-dialog（"机场港口"960px, close-on-click-modal=false），非跳转。地区四级联动（国家→州省→城市→区县）。

## 筛选项
1. 港口类型 el-select placeholder=港口类型 clearable filterable width130：机场=0/港口=1/火车站=2/口岸=4(typeList 本地固定)。
2. 所在国家 el-select clearable filterable @focus getCountryList @change onCountryChange(1)，countryList label=`${name}-${alias}` value=id。
3. 州/省 el-select :disabled="!countryId" :loading @focus getStateList(1) @change onStateChange(1)，stateList1。
4. 城市 el-select :disabled="!stateId" @focus getCityList(1) @change onCityChange(1)，cityList1。
5. （区/县已注释）
6. 关键字 el-input width280，prepend el-select(selectType：港口名称=1/三字代码=2)，placeholder 请输入内容。查询时 selectType=1→name，=2→code。
- 查询：v-permission="['queryPort']" @click getPortList(1)。无重置。

## 表格列
- 港口类型 width120 slot formattType(type)
- 港口名称 prop=name min180
- 英文名称 prop=alias min180
- 三字代码 prop=code width120
- 国家/地区 prop=countryName width180 tooltip
- 州省市区 width200 slot：stateName > cityName > countyName(v-show)
- 海关 prop=hsName width120 tooltip
- 添加时间 prop=createTime width170
- 操作 width130 fixed=right：编辑/删除

## 操作按钮
- 新增港口：addPort，type=text icon=circle-plus-outline @click addPort。
- 查询：queryPort。
- 编辑：editPort @click editPort(联动加载 state/city/county + getOrgList)。
- 删除：deletePort，$confirm('请确认是否删除该条数据?','温馨提示',warning) → deletePort。

## 新增/编辑表单字段（label-width100, inline 各49.5%）
- 国家/地区 prop=countryId el-select filterable @focus getCountryList @change onCountryChange(2)；required change
- 州/省 prop=stateId :disabled="!countryId"；required change
- 城市 prop=cityId :disabled="!stateId"；required change
- 区/县 prop=countyId :disabled="!cityId"；required:false
- 港口类型 prop=type el-select(typeList)；required
- 港口名称 prop=name maxlength50；required blur「港口名称不能为空」
- 英文名称 prop=alias maxlength50；required blur + validator 禁中文「英文名称不能为中文」
- 三字代码 prop=code maxlength8 show-word-limit；required blur + validator /^[a-zA-Z0-9]*$/「只能是数字、字母」+ length<3「不能少于三位」
- 详细地址 prop=address maxlength100；required blur「详细地址不能为空」
- 详细邮编 prop=postal maxlength10 show-word-limit；required blur + validator /^[a-zA-Z0-9]*$/「只能是数字、字母」
- 海关 prop=hsCode el-select filterable @focus getOrgList(type=0 按地区过滤)，orgList。无校验。
- 保存 savePort 前回填 countryName/hsName/stateName/cityName/countyName。

## 目标页现状
- SearchBar(港口名称/类型 PORT_TYPES/状态) + ProTable + Modal。列 name/code(港口代码)/type/country(input)/status(switch)/createTime。表单 名称/代码/类型/国家(input)/状态(radio)。rules name 必填、type change。无地区级联、无关键字类型切换、无 v-permission。

## 差异
- 需补：地区四级联动(筛选+表单)、关键字 prepend 类型切换(港口名称/三字代码)、表格 英文名称/州省市区拼接/海关/类型映射(0/1/2/4)、表单 alias/code(三字代码 maxlength8)/address/postal/hsCode(海关下拉)及全部校验、权限键 addPort/queryPort/editPort/deletePort、海关 getOrgList、保存前 name 回填。
- 需删/确认：status 开关列及 toggle(源无)、country 纯文本(源是国家下拉 id)、PORT_TYPES 字符串(源 0/1/2/4)、重置按钮。
- 字段映射：目标 code=港口代码 vs 源 code=三字代码(maxlength8)；目标 country(文本) vs 源 countryId+countryName；源 type=0/1/2/4。
- 工作量：极大。
