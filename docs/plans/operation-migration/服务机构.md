# 服务机构 service-agency/index.vue → src/views/operation/ServiceAgency.vue

## 源页结构
- 单页(无树/无tab)。head-info title=服务机构。顶部工具行(新增 + 多筛选) + 表格 + 分页 + 3 弹窗：新增/编辑机构(960px)、关联服务国家 el-transfer(960px)、商品图片预览(540px append-to-body)。
- 表单弹窗内含 国家→州→城市→区县 级联 select（stateList2/cityList2/countyList2）+ logo 上传 + 关联服务国家穿梭。

## 筛选项
1. 机构类型 el-select selectValue.type clearable：海关=0/船东=1/空运公司=2/铁路公司=3/快递公司=4/卡派公司=5。
2. 服务国家 el-select serviceCountry filterable @focus getCountryList，选项 countryList(label=`name-alias`)。
3. 国家/地区 el-select countryId filterable @focus getCountryList @change onCountryChange(1)。
4. 州/省 el-select stateId :disabled="!countryId" @focus getStateList(1) @change onStateChange(1)。
5. 城市 el-select cityId :disabled="!stateId" @focus getCityList(1) @change onCityChange(1)。
6. （区/县筛选已注释）
7. 机构名称关键字 el-input name placeholder=请输入机构名称关键字。
- 查询：v-permission="['queryServiceOrg']" @click queryAll(1)。

## 表格列
- 机构类型 prop=type width100：typeFilter(0海关/1船东/2空运/3铁路/4快递/5卡派)
- 机构名称 prop=name min150 sortable="custom"(sortChange→nameSort D/A)
- 英文名称 prop=alias min150
- 全球代码 prop=code width120
- 服务国家 width100：按钮"服务国家"，:disabled="!$checkPermission(['serviceOrgCountry'])"，@click editCountry(row)(打开穿梭,isOut=true 直接保存)
- 国家/地区 prop=countryName width180 tooltip
- 州省市区 width200 tooltip：stateName > cityName > countyName(v-show 各段)
- 网址链接 width100：<a :href=row.url target=_blank>点击访问</a>
- 操作 width130 fixed=right：编辑/删除
- 表格高度 calc(100vh-313px)，size=10。

## 操作按钮（权限键逐字）
- 新增机构：addServiceOrg，type=text icon=circle-plus-outline @click addOrgan。
- 查询：queryServiceOrg。
- 服务国家(列内)：$checkPermission(['serviceOrgCountry'])。
- 编辑：editServiceOrg @click editOrgan(异步回填级联 state/city/county)。
- 删除：deleteServiceOrg，$confirm('请确认是否删除该条数据?','温馨提示',warning) → deleteOrgan。

## 新增/编辑表单字段（弹窗 960px, label-width100, 每项 inline 49.5%）
- 机构类型 prop=type：el-select(6 选项)。required change「请选择机构类型」
- 国家/地区 prop=countryId：el-select filterable @focus getCountryList @change onCountryChange(2)。required change
- 州/省 prop=stateId：el-select clearable filterable :disabled="!countryId"。required change
- 城市 prop=cityId：el-select :disabled="!stateId"。required change
- 区/县 prop=countyId：el-select :disabled="!cityId"。required=false change
- 服务国家 prop=serviceIds：只读 input(placeholder=`已选择(${serviceIds.length})`) + append 搜索 @click onServiceCountry(el-transfer)。required blur「请选择服务国家或地区」
- 机构名称 prop=name：el-input clearable maxlength50。required blur「机构名称不能为空」
- 英文名称 prop=alias：el-input maxlength50。required blur + validator 禁中文(/[一-龥]/)
- 全球代码 prop=code：el-input maxlength20。required blur + validator /^[a-zA-Z0-9\s]*$/「全球代码只能包含数字、字母」
- 链接网址 prop=url：el-input maxlength100。validator validateLink(isValidURL) 非必填
- logo(无prop)：el-upload(before-upload 图片格式+2MB；http-request→$upload OSS jht-admin/service-agency/logo/...；放大 magnifyFile/删除 removeFile)
- 保存 saveConfirm：回填 countryName/stateName/cityName/countyName + serviceCountry=serviceIds.join(',') → saveOrgan。

## 详情/次级弹窗/子页
- 关联服务国家弹窗(960px)：el-transfer v-model serviceIds, filterable, filter-method 按 name, titles ['关联服务国家','已选择'], props {key:id,label:label}, data=countryList。transferConfirm：isOut(列内入口)直接 saveOrgan，否则仅关闭。
- 图片预览弹窗(540px append-to-body)：展示 imgUrl。

## 目标页现状
- SearchBar：机构名称/类型 AGENCY_TYPES/状态。列：name/code/type/contact/status(switch)/createTime。表单：名称/编码/类型/联系人/状态。校验 name+type 必填。无级联、无穿梭、无 logo、无网址列、无排序。

## 差异
- 需补：国家/州/城市/区县四级级联(筛选+表单各一套)；服务国家 el-transfer 穿梭 + 列内直接编辑(isOut)；logo 上传+图片预览；机构类型 6 值枚举(0-5)+typeFilter；sortable custom(nameSort)+服务国家/州省市区/网址列；alias/code/url 三处 validator；权限键 addServiceOrg/queryServiceOrg/editServiceOrg/deleteServiceOrg/serviceOrgCountry；API getSeviceOrganList 等。
- 需删/确认：status 列+toggle、contact、AGENCY_TYPES 文本枚举(源为数字0-5)、状态筛选。
- 字段映射：name→name；code→code(全球代码)；type→type(数字0-5)；源 alias/url/img/countryId/stateId/cityId/countyId/serviceCountry 目标全缺；源无 contact。
