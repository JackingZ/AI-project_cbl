# 车型管理 vehicle-management/index.vue → src/views/operation/VehicleManagement.vue

## 源页结构
- 单页 head-info(车型管理) + app-panel。左上"新增车型"，右上筛选。el-table + 分页。
- 两 el-dialog：① 新增/编辑车型(900px)；② 国家/地区穿梭框(el-transfer 960px)。单位来自数据字典 getWordsList。

## 筛选项
1. 国家/地区 el-select filterable clearable @focus getCountryList，countryList label=`${name}-${alias}` value=id。selectValue.countryId。
2. 车型名称关键字 el-input clearable placeholder=车型名称关键字 selectValue.name。
- 查询：v-permission="['queryVehicleType']" @click queryAll(1)。

## 表格列
- 国家/地区 :formatter=formatCountry(countries.map countryName join) min200 tooltip
- 车型名称 prop=name
- 英文名称 prop=alias
- 车长 length formatterUnit(umLengthList,'umLength') min100
- 车宽 width formatterUnit(umLength) min100
- 车高 height formatterUnit(umLength) min100
- 装载体积 volume formatterUnit(umVolumeList,'umVolume') min100
- 最大限重 loadLimit formatterUnit(umWeightList,'umWeight') min100
- 座位数 seats width110
- 操作 fixed=right width160：编辑/删除

## 操作按钮（权限键）
- 新增车型：addVehicleType icon=circle-plus-outline @click addCar。
- 查询：queryVehicleType。
- 编辑：editVehicleType @click editVehicle(回填 selectForm, area=countries.map countryId)。
- 删除：deleteVehicleType，$confirm('请确认是否删除该条数据?','温馨提示',warning) → deleteVehicle。

## 新增/编辑表单字段（label-width100, inline 各50%）
- 国家/地区 prop=area：disabled el-input 显示`已选择(${area.length})`, append 搜索 @click handleStates 打开穿梭框；required change「国家/地区不能为空」
- 车型名称 prop=name el-input；required blur「车型名称不能为空」
- 英文名称 prop=alias maxlength20；required blur + validator 禁中文「英文名称不能有中文」
- 长度单位 prop=umLength el-select(字典 measurement_type) @change onLength(联动设 umVolume：CM→CBCM/M→CBM/IN→CUIN/FT→CUFT)；required change
- 体积单位 prop=umVolume el-select disabled(字典 VOLUME_TYPE, 由 umLength 联动)；required change
- 重量单位 prop=umWeight el-select(字典 weight_type)；required change
- 长度 prop=length el-input-number controls=false min1 max9999 precision2；required blur
- 宽度 prop=width 同上；required blur
- 高度 prop=height 同上；required blur
- 装载体积 prop=volume el-input-number min1 max999999 precision2；required change
- 最大限重 prop=loadLimit min1 max999999 precision2；required blur
- 座位数 prop=seats el-input-number step1 step-strictly min1 max100；required blur
- 保存 saveVehicleType：area→countries[{countryId,countryName}]。

## 详情/次级弹窗/子页
- 国家/地区穿梭框 el-transfer：filterable, filter-method, titles ['国家/地区','已选择'], props {key:id,label:label}, data=countryList, v-model selectForm.area。

## 目标页现状
- SearchBar(车型名称/车辆类型 VEHICLE_TYPES/状态) + ProTable + Modal。列 name/type/load(载重吨)/volume(容积m³)/status/createTime。表单 车型名称/类型/载重/容积/状态。默认 type='厢式货车'。无 v-permission。

## 差异
- 需补：国家/地区穿梭框(el-transfer)、国家筛选、单位字典三类(umLength/umVolume/umWeight)+长度联动体积 onLength、length/width/height/volume/loadLimit/seats(min/max/precision/step)、alias 中文校验、formatCountry/formatterUnit、权限键 addVehicleType/queryVehicleType/editVehicleType/deleteVehicleType。
- 需删/确认：车辆类型 type 枚举 VEHICLE_TYPES(源无 type，分类维度是国家 countries)、load/volume 简化字段、status 开关、createTime 列。
- 字段映射：目标 volume(容积) vs 源 volume(装载体积+umVolume)；目标 load vs 源 loadLimit(+umWeight)；源 seats/length/width/height/alias/area 目标全缺。
- 工作量：极大。
