# 岗位提成一致性核对（源 workProject2-jht Vue2 → 目标 Vue3）

- 源：`agent/workProject2-jht/src/views/system-management/job-commission/index.vue`（单文件，含更新提成弹窗 + 查看提成弹窗）
- 目标：`src/views/system/JobCommission.vue`（单文件通用 CRUD，mock=`commissionApi`，字段虚构）

> 背景约定：所属公司 custId 标【设计简化】；深操作可 demoAction。**核心结论：源是"按重量/体积/票/箱 计量 + 区间阶梯提成 + 版本管理"的复杂业务；目标虚构成"提成方式 固定/比例 + 提成比例(%)"的简单 CRUD，业务模型根本错配。**

---

## 1. 筛选项
- 源：所属公司 custId【设计简化】、计量方式 commissionType(按重量/按体积/按票/按箱)、岗位名称 postName。
- 目标：岗位名称 name、提成方式 type(固定/比例)、状态 status。

| 判定 | 项 | 说明 |
|---|---|---|
| 字段差异=错配 | 计量方式：源=按重量/体积/票/箱；目标=固定/比例 | 枚举语义完全不同 |
| 目标有源无=错配 | 状态 status 筛选 | 源无状态概念 |
| 一致 | 岗位名称 | postName vs name |

## 2. 表格列
- 源列：所属公司(companyFilter)、岗位名称 postName、计量方式 type(按重量/体积/票/箱)、计量单位 um、最新版本 version、最新版本日期(startDate 至 endDate)、**更新提成**(按钮列，权限 `commissionUpdate`)、操作(查看 `commissionGet`)。
- 目标列：岗位名称 name、提成方式 type、提成比例(%) ratio、状态 status(switch)、创建时间。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **计量单位 um** |
| 源有目标无=需补 | **最新版本 version + 版本日期区间**(版本管理机制) |
| 源有目标无=需补 | **"更新提成"按钮列** |
| 源有目标无=需补 | **区间阶梯提成明细**(查看弹窗内子表：区间下限/上限/提成金额) |
| 目标有源无=错配 | 提成比例(%) ratio、状态 status switch | 源无单一比例值，无状态切换 |
| 字段差异=错配 | 计量方式枚举 |
| 设计简化 | 所属公司列 |

## 3. 表单字段
- 源无"新增/删除"CRUD，改为两个弹窗：
  - **更新提成弹窗**：计量方式 type、计量单位 um(随 type 联动 KGS/LBS/CBM/IVC/BOX 等)、起止日期 time(daterange，或已生效时拆起始/截止单选)、**区间&提成 sections**(多行：下限 lower / 上限 upper / 单位金额 amount，可增删，含区间不重叠/下限<上限/完整性校验)。含 timeCompare 时间态(未开始0/进行中1/已结束2)控制可编辑性。
  - **查看提成弹窗**：版本下拉切换 + 子表(计量方式/计量单位/区间下限/上限/提成金额)，进行中态可编辑行。
- 目标表单：岗位名称 name、提成方式 type(固定/比例)、提成比例(%) ratio、状态 status(radio)。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **计量单位 um**(按 type 联动) |
| 源有目标无=需补 | **起止日期 time**(daterange) |
| 源有目标无=需补 | **区间阶梯提成 sections**(多行增删+重叠/大小校验) 核心业务 |
| 源有目标无=需补 | **版本管理**(version 下拉、时间态 timeCompare 控制可编辑) |
| 目标有源无=错配 | 岗位名称输入(源岗位来自 postName 只读)、提成比例(%)、状态 |
| 字段差异=错配 | 整体业务模型：源=阶梯区间×计量单位×版本；目标=单一比例值 |

## 4. 操作按钮 + v-permission
源逐字权限键：查询 `commissionQuery`、更新提成 `commissionUpdate`(`$checkPermission`)、查看 `commissionGet`；(删除 deteleCommission 已注释)。
目标：0 权限；通用"新增/编辑/删除"。

| 判定 | 项 |
|---|---|
| 需补(权限) | 3 个权限键未接入 |
| 源有目标无=需补 | **更新提成、查看(版本+区间明细)** 两大操作缺失 |
| 目标有源无 | 新增/删除/状态切换：源无这些操作 |

## 5. 子组件/弹窗
| 判定 | 项 |
|---|---|
| 源有目标无=需补 | 更新提成弹窗(sections 阶梯编辑)、查看弹窗(版本切换+子表) 均缺 |

## 一致性评分：岗位提成 **18 / 100**
最严重错配页之一。源为"计量方式×计量单位×区间阶梯提成×版本管理"复杂业务，目标虚构为"提成方式 固定/比例 + 单一比例%"的通用 CRUD，业务模型、操作(更新提成/查看版本)、区间阶梯核心逻辑全部缺失。需整页按源业务重写。
