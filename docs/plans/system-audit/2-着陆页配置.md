# 着陆页配置 PcConfig 一致性核对

- 源：`agent/workProject2-jht/src/views/system-management/pc-config/index.vue`（Vue2）
- 目标：`src/views/system/PcConfig.vue`（Vue3 通用 CRUD 骨架）
- 源权限键：`indexConfigSave`（保存）/ `indexConfigUpload`（上传）；路由 role `indexConfig`
- 一致性评分：**严重错配**（目标完全是模板 CRUD，与源真实页面无关）

## 结论速览
源**不是列表页**，而是一个「着陆页/官网首页」的**单表单配置页**：多图上传（导航 logo / 5 张 banner / 底部 logo / 2 张底部二维码）+ 联系电话 + 工作时间，保存整份 JSON。目标却做成了「配置项 键/值 列表 + 新增/编辑/删除弹窗」的通用 CRUD——**页面形态、字段、交互全部对不上**，属最需整页重写的一页。

## 筛选项
| 项 | 源 | 目标 | 结论 |
|----|----|----|----|
| 配置项 name 输入 | 无 | 有 | 【目标虚构】源无列表故无筛选 |
| 状态 select | 无 | 有 | 【目标虚构】 |

## 表格列
源**无表格**（整页是一个 el-form）。目标虚构了列表：
| 目标列 | 结论 |
|----|----|
| 配置项 name / 键 ckey / 值 cvalue / 状态 / 创建时间 | 【全部目标虚构】源无任何列表列 |

| 源字段 | 类型 | 目标 | 结论 |
|----|----|----|----|
| 首页导航 logo navData | el-upload 单图（建议 70x42）| 无 | 【源有目标无=需补】 |
| 首页 banner banner1~5Data | el-upload 最多 5 图（建议 448x278）| 无 | 【需补】 |

| 工作时间 time | el-input maxlength 50 | 无 | 【需补】 |
| 配置项 name / 键 ckey / 值 cvalue / 状态 status | 无 | 有 | 【目标全虚构】 |

## 详情字段
源无详情弹窗（表单即配置）。目标的编辑弹窗为虚构。

## 操作按钮
| 按钮 | 源文案/权限/交互 | 目标 | 结论 |
|----|----|----|----|
| 保存 | `保 存`，`v-permission=['indexConfigSave']`，校验后 savePage 存 JSON | 无对应；目标是弹窗内「确定」提交单条 | 【需补】can **save**（indexConfigSave）|
| 上传（各图）| `$checkPermission(['indexConfigUpload'])` 控制 el-upload disabled | 无 | 【需补】can **upload**（indexConfigUpload）|
| 删除图 | 图片 hover 删除图标 → 二次确认 → $deleteLoad + 重新保存 | 无 | 【需补】随图上传能力一并缺失 |
| 新增/编辑/删除（行）| 无 | 有 | 【目标全虚构】源无 CRUD 行操作 |

## 子组件
无（源用全局 `$upload` / `$deleteLoad` / `$checkPermission`）。目标用通用 SearchBar/ProTable/Modal。

## 建议 can 动作
- can save（源 indexConfigSave）——保存整份着陆页配置
- can upload（源 indexConfigUpload）——控制各图上传按钮可用
- 无 can add/edit/del（源无列表 CRUD，目标全属虚构）

## 需补要点（真实业务缺漏）
整页重写：把通用列表 CRUD 换成单表单配置页——
1. 多分组图片上传：导航 logo(1)、banner(≤5)、底部 logo(1)、底部二维码(≤2, 各带标题)，含尺寸提示与删除。
2. 联系电话（禁中文校验）、工作时间（maxlength 50）两输入。
3. 顶部「保存」按钮统一提交（JSON 内容）。
4. 移除虚构的筛选区 / 键值列表 / 行级增删改 / 状态列。
