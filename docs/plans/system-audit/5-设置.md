# 设置 JhtSet 一致性核对

- 源：`agent/workProject2-jht/src/views/system-management/jht-set/index.vue`（仅壳）
  - 实际内容 = 复用 `@/views/organizers-management/common-setting/more/attachInfo.vue`（6 个 tab 的多子表维护）
- 目标：`src/views/system/JhtSet.vue`（Vue3 通用 CRUD 骨架，name=SysSet）
- 源权限键：路由 role `jhtSetion`，isJHT: true；attachInfo 内各操作**无 v-permission**（纯页面级）
- 一致性评分：**严重错配**（源是聚货通自身档案的 6-tab 维护台，目标是键值 CRUD）

## 结论速览
源「设置」页把聚货通自身（currentCustId='0', custType='jht'）当作一个组织，复用组织管理的 attachInfo 组件，提供 **6 个 tab**：联系信息 / 地址信息 / 我的设置 / 收款信息 / 开票信息 / 文件列表，每个 tab 是一张带增删改的子表（多个 add-edit 弹窗子组件）。目标做成了「设置项 名/键/值/状态」的单表 CRUD，**6 个业务子表全部丢失**。这是 6 页里体量最大、最需要重建的一页。

## 表格列（各 tab，源真实字段 —— 目标全缺）
- **联系信息**：所有国家 countryName / 所属部门 dept / 职务类型 duty / 姓名 name / 电话·手机 tel+phone / 电子邮箱 email / 其他联系方式 sns / 地址 address / 最后更新 updateTime。
- **地址信息**：默认(radio setDefaultAddress) / 地址类型(formatter) / 地址名称 name / 所在国家 countryName / 州省市区 / 地址 address / 关联对接人 contactName / 最后更新。
- **我的设置**：类型(formatter) / 联系人 contact / 所在国家 / 州省市区 / 公司名称 company / 联系电话 phone / 电子邮箱 email / 联系地址 address / 是否有效 status / 最后更新。
- **收款信息**：收款方式(formatType) / 国家地区 countryName / 币种 currencyName / 收款账号 acctNo / SWIFT Code swiftCode / 备注 remark / 最后更新 / 附件(预览)。
- **开票信息**：开票名称 name / 纳税识别号 taxId / 开户银行 bank / 国家地区 / 币种 / 每月额度 amount / 备注 / 最后更新。
- **文件列表**：文件名称 name / 文件类型(formatFileType) / 编码·ID code / 文件描述 des / 最后更新。

目标列：设置项 name / 键 skey / 值 svalue / 状态 / 创建时间 —— 【全部目标虚构】。

## 子组件（源独有）

## 建议 can 动作
- 每个 tab：can add / can edit / can del
- 地址、我的设置：can setDefault
- 收款、文件：can preview
- 源无按钮级权限键（页面级 jhtSetion + isJHT），can 动作按页面统一即可
- 无 can toggle（目标状态开关属虚构）

## 需补要点（真实业务缺漏）
整页重建为「聚货通档案 6-tab 维护台」（复用/移植 attachInfo 结构）：
1. 6 个 tab：联系信息 / 地址信息 / 我的设置 / 收款信息 / 开票信息 / 文件列表（收款+开票仅非 customer 显示——单角色下可固定显示）。
2. 各 tab 独立子表 + 增/删/改弹窗，字段按上表。
3. 地址/我的设置的「默认」单选；收款/文件「预览」。
4. 我的设置 tab 的 类型/服务国家 筛选 + 查询。
5. 移除虚构的单表键值 CRUD。
