# 车辆管理一致性核对（源 workProject2-jht Vue2 → 目标 Vue3）

- 源：`agent/workProject2-jht/src/views/system-management/car-management/index.vue` + `components/addeditform.vue`
- 目标：`src/views/system/CarManagement.vue`（单文件通用 CRUD，mock=`carApi`，字段虚构）

> 背景约定：所属公司 custId、供应商下拉标【设计简化】。**核心结论：目标虚构"车型 厢式/平板/冷藏 + 载重(吨) + 司机"，与源真实车辆档案（关联车型/车况/保险/尾板/GPS）错配。**

---

## 1. 筛选项
- 源：所属公司 custId【设计简化】、车牌号 plateNumber。
- 目标：车牌号 name、车型 type(厢式/平板/冷藏)、状态 status。

| 判定 | 项 | 说明 |
|---|---|---|
| 目标有源无=错配 | 车型 type、状态 status 筛选 | 源列表筛选仅车牌号（车况/状态非筛选项） |
| 一致 | 车牌号 | prop 命名不同(plateNumber vs name) |

## 2. 表格列
- 源列：车牌号 plateNumber、车型 vehicleTypeName、上牌时间 plateDate(YYYY-MM-DD)、车况 grade(良好/维修/其他)、保险到期日 expire、三者险保额 insurance、是否有尾板 tailboard(√/×)、是否有GPS gps(√/×)、所属公司 custName、操作。
- 目标列：车牌号 name、车型 type、载重(吨) load、司机 driver、状态 status、创建时间。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **上牌时间 plateDate** |
| 源有目标无=需补 | **车况 grade**(良好/维修/其他) |
| 源有目标无=需补 | **保险到期日 expire** |
| 源有目标无=需补 | **三者险保额 insurance** |
| 源有目标无=需补 | **是否有尾板 tailboard**(√/×) |
| 源有目标无=需补 | **是否有GPS gps**(√/×) |
| 目标有源无=错配 | 载重(吨) load、司机 driver、状态 status | 源无此三列，虚构 |
| 设计简化 | 所属公司 custName 列 |
| 备注 | 源列表**无状态 switch**（车辆无启用/禁用切换，仅司机管理有）；目标却有状态列——虚构 |

## 3. 表单字段（addeditform）
- 源新增/编辑：所属公司 custId、车牌号 plateNumber(正则校验+编辑时禁改)、上牌时间 plateDate(不可选未来)、关联车型 vehicleTypeId(下拉)、车况 grade(良好/维修/其他)、保险到期日 expire、三者险保额 insurance(数字 precision2)、是否有尾板 tailboard(radio 是/否)、是否有GPS gps(radio 是/否)。
- 目标表单：车牌号 name、车型 type、载重(吨) load、司机 driver、状态 status。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **上牌时间 plateDate**(禁选未来日) |
| 源有目标无=需补 | **关联车型 vehicleTypeId**(远程下拉，非固定枚举) |
| 源有目标无=需补 | **车况 grade** |
| 源有目标无=需补 | **保险到期日 expire** |
| 源有目标无=需补 | **三者险保额 insurance**(数字) |
| 源有目标无=需补 | **是否有尾板 tailboard、是否有GPS gps**(radio) |
| 目标有源无=错配 | 载重(吨) load、司机 driver、状态 status |
| 字段差异 | 车牌号：源带车牌正则校验+编辑禁改；目标仅 required。车型：源远程 vehicleTypeList；目标固定枚举 CAR_TYPES |

## 4. 操作按钮 + v-permission
源逐字权限键：新增车辆 `addVehicle`、查询 `queryVehicle`、编辑 `editVehicle`、删除 `deleteVehicle`。
目标：0 权限接入，通用"新增/编辑/删除"。

| 判定 | 项 |
|---|---|
| 需补(权限) | 4 个权限键未接入 |
| 字段差异 | 源弹窗 footer 手动确认(调子组件 saveUser)；目标通用 Modal @confirm |
| 目标有源无 | 状态 switch(toggle)：源车辆无此操作，目标多出 |

## 5. 子组件
| 判定 | 项 |
|---|---|
| 源有目标无=需补 | `addeditform.vue`(车型远程下拉/车况/保险/尾板/GPS) 目标未拆分且字段错配 |

## 一致性评分：车辆管理 **30 / 100**
主要扣分：目标虚构"载重/司机/状态开关"错配真实车辆档案；缺上牌时间、关联车型、车况、保险到期日、三者险保额、尾板、GPS 全部核心字段；车牌正则校验缺失；权限键 0 接入。属结构性字段错配。
