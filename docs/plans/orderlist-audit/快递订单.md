## 四、详情弹窗字段（源 detail.vue vs 目标 OrderDetailDialog 快递分支）

源 detail：寄件人信息(联系人/电话/邮箱/邮编/公司/联系地址/详细地址1/2)、收件人信息、货物/包裹明细、历史查看+更新快递状态+同步快递单号操作。
目标快递分支：快递公司/快递单号/收件人/收件邮编 + 通用基础信息。

结论：详情大幅简化。**缺漏（保真需补）**：寄件人完整信息(consignor/phone/mail/zip/company/address)、收件人详细地址、包裹明细、历史/更新/同步快递状态操作。按弹窗简化策略可接受，标注。

## 五、权限键接入（当前 0 接入）

源键：`deliveryOrderQuery`(查询)、`deliveryOrderGet`(查看)、`expressReSubmit`(重新提交)、`revokeExpress`(撤单)、`changeOrderExpress`(换单)、`downExpressTags`(更多下载类)。

建议 ExpressOrder 接入 can：
- `can('query')` → 查询（deliveryOrderQuery）
- `can('view')` → 查看（deliveryOrderGet）
- `can('resubmit')` → 重新提交（expressReSubmit）
- `can('revoke')` → 撤单（revokeExpress）
- `can('swap')` → 换单（changeOrderExpress）
- `can('download')` → 更多▾ 下拉整体（downExpressTags）
