## 四、详情弹窗字段（源 detail.vue vs 目标 OrderDetailDialog 订舱分支）

目标订舱分支：SO号/提单号/起运港/目的港/柜号 + 通用基础信息。
源 detail 为完整订舱详情页（服务/港口/柜信息/费用等，另有 collapseItem 订单进度、orderFinancial 账单）。

结论：详情简化。缺漏（保真需补）：放货条款、服务条款、柜信息明细、费用信息等。按弹窗简化可接受，标注。

## 五、权限键接入（当前 0 接入）

源键：`bookingOrderQuery`(查询)、`bookingOrderView`(查看)、`bookingOrderCancel`(取消)、`bookingOrderDelete`(删除)、`bookingOrderFinancial`(账单)；审核/进度/指定供应商源无键。

建议 BookingOrder 接入 can：
- `can('query')` → 查询（bookingOrderQuery）
- `can('view')` → 查看（bookingOrderView）
- `can('cancel')` → 取消（bookingOrderCancel）
- `can('del')` → 删除（bookingOrderDelete）
- `can('bill')` → 账单信息（bookingOrderFinancial）
- 审核/订单进度/指定供应商源无键，可用 `can('audit')`/`can('progress')`/`can('assign')` 自定义或不接

操作集合完整对齐、前置关键字下拉完整、跳转弹窗化到位。扣分：**服务(serviceId)筛选项缺失**、**5个柜态统计列缺失**（真实缺漏，非纯简化）；详情字段缩减；0 权限键接入；业务类型必选门槛/联动禁用未复刻。
