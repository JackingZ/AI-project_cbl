# 更多附加信息（common-setting/more）一致性核对

- 源：`agent/workProject2-jht/src/views/organizers-management/common-setting/more/`
  - `attachInfo.vue`（Tab 容器 + 6 表格）
  - 子记录弹窗：`addEditPerson`(联系) / `addEditAddress`(地址) / `addEditSetting`(我的设置) / `addEditCollection`(收款) / `addEditBill`(开票) / `addEditFile`(文件)
- 目标：`src/components/Common/MoreInfoPanel.vue`（配置化单 Modal 面板）+ `src/api/modules/organizerMore.js`（mock）

> 背景约定：目标为配置化重建（ALL_TABS 驱动），客户隐藏“收款/开票”(ownerOnly)。此为既定设计。以下重点核对**字段缺漏、选项枚举、必填与上传**。

---

## 0. 标签页结构

源 6 Tab：联系信息 / 地址信息 / 我的设置 / 收款信息(非 customer) / 开票信息(非 customer) / 文件列表。
目标 6 Tab：contact / address / setting / collection(ownerOnly) / bill(ownerOnly) / file。
判定：**一致**（数量、顺序、客户隐藏收款+开票 均对齐）。

## 1. 联系信息（addEditPerson → contact）

源字段：联系人姓名 name(必填) / 英文名称 alias / 所属部门 dept(必填) / 职位名称 duty(必填) / 国家/地区 countryId(必填) / 联系电话 tel(必填) / 手机号码 phone / 电子邮箱 email(必填+格式) / **传真号码 fax** / 其他联系方式 sns / 联系地址 address / **备注 remark**。
目标字段：所在国家 country / 所属部门 dept / 职务类型 duty / 姓名 name / 电话 tel / 手机 phone / 电子邮箱 email / 其他联系 sns / 地址 address。required：仅 name。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | 英文名称 alias、**传真号码 fax**、备注 remark |
| 字段差异 | 必填：源 name/dept/duty/countryId/email(格式)/tel 均必填；目标仅 name |
| 字段差异 | 标签：联系人姓名→姓名、职位名称→职务类型、联系电话→电话、手机号码→手机、国家/地区→所在国家 |
| 字段差异 | 列“电话/手机”：源表格 tel+phone 双行展示；目标单值 |

## 2. 地址信息（addEditAddress → address）

源字段：地址名称 name(必填) / **地址类型 type(必填)** / 国家/地区 countryId / 州省 stateId / 城市 cityId / 区县 countyId / 联系地址 address(必填) / **邮政编码 postal** / 关联对接人 contactId(必填,**下拉选人**) / **是否集货地址 store(是/否)** / 备注 remark。默认地址：表格 radio → setDefaultAddress。
目标字段：地址类型 addrType / 地址名称 name / 所在地区 region(cascader) / 地址 address / 关联对接人 contactName(**文本输入**) / 设为默认 isDefault(bool)。required：name。

| 判定 | 项 |
|---|---|
| 字段差异（重点） | **地址类型选项完全不同**：源=办公室/客服部/提货仓库/到货仓库；目标 ADDRESS_TYPES=发货地址/收货地址/退货地址 |
| 源有目标无=需补 | 邮政编码 postal、是否集货地址 store、备注 remark |
| 字段差异 | 关联对接人：源=从联系人列表下拉(contactId)；目标=自由文本(contactName) |
| 字段差异 | 必填：源 name/type/countryId/state/city/address/contactId；目标仅 name |
| 一致 | 设为默认功能（源表格 radio / 目标 isDefault + 操作列“设为默认”）对齐 |

## 3. 我的设置（addEditSetting → setting）

源字段：设置类型 type(必填) / 联系人 contact(必填) / 国家地区 countryId / 州省 / 城市 / 区县 / 公司名称 company(必填) / **邮政编码 postal(必填)** / 联系电话 phone(必填) / 联系邮箱 email(必填) / 联系地址 address(必填) / 是否有效 status(是/否,必填) / **服务国家 serviceCountryId** / **是否公开 open（type=报关抬头时）** / **证件类型 certType(必填)** / **证件号码 certNumber(必填)** / **上传照片 photo(必填)**。Tab 内含搜索：类型 + 服务国家 + 查询。
目标字段：类型 settingType / 联系人 contact / 所在地区 region / 公司名称 company / 联系电话 phone / 电子邮箱 email / 联系地址 address / 是否有效 valid(有效/无效)。required：contact。

| 判定 | 项 |
|---|---|
| 字段差异（重点） | **设置类型选项完全不同**：源=发货人/收货人/通知人/进口商/海外代理/订舱代理/报关抬头；目标 SETTING_TYPES=报关行/目的港代理/海外仓/拖车行 |
| 源有目标无=需补 | 邮政编码 postal、服务国家 serviceCountryId、是否公开 open、**证件类型 certType、证件号码 certNumber、上传照片 photo** |
| 源有目标无=需补 | **Tab 内搜索区**（类型 + 服务国家 + 查询）；目标面板无 per-tab 搜索 |
| 字段差异 | 是否有效：源 status(是/否 → 表格显示有效/无效)；目标 valid(有效/无效)，语义同 |

## 4. 收款信息（addEditCollection → collection，非 customer）

源字段：国家地区 countryId(必填) / 币种 currencyId(必填) / 收款方式 type(必填) / **账户名称 acctName(必填)** / 收款账号 acctNo(必填) / 备注 remark / **上传附件 attach(type 银行卡/微信 时必填)** / **银行中文名称 bankName / 银行英文名称 bankAlias / 银行代码 bankCode / 分行代码 branchCode / 银行地址 bankAddress** / Swift Code swiftCode。
目标字段：收款方式 collType / 国家地区 country / 币种 currency / 收款账号 acctNo / SWIFT Code swiftCode / 备注 remark。required：acctNo。

| 判定 | 项 |
|---|---|
| 字段差异 | **收款方式选项不同**：源 paywayList=银行卡/微信/支付宝/PayPal/其它；目标 COLLECTION_TYPES=银行转账/PayPal/西联汇款/支付宝 |
| 源有目标无=需补 | 账户名称 acctName、上传附件 attach、**银行中英文名称/银行代码/分行代码/银行地址**（整组银行明细缺） |

## 5. 开票信息（addEditBill → bill，非 customer）

源字段：开票名称 name(必填) / 纳税识别号 taxId(必填) / 开户银行 bank(必填) / 每月额度 amount(必填,数字) / 国家地区 countryId(必填) / 币种 currencyId(必填) / 备注 remark。
目标字段：开票名称 name / 纳税识别号 taxId / 开户银行 bank / 国家地区 country / 币种 currency / 每月额度 amount / 备注 remark。required：name。

| 判定 | 项 |
|---|---|
| 一致（最佳匹配） | 字段完全对齐 |
| 字段差异 | 仅必填数量差异（源多字段必填 + amount 数字校验；目标仅 name） |

## 6. 文件列表（addEditFile → file）

源字段：文件类型 type(必填) / 文件名称 name(必填) / 编码/ID code(必填) / **上传文件(必填)** / 文件描述 des。
目标字段：文件名称 name / 文件类型 fileType / 编码/ID code / 文件描述 des。required：name。

| 判定 | 项 |
|---|---|
| 字段差异 | **文件类型选项不同**：源 fileTypeList=电子合同/营业执照/身份证正面/身份证反面/WCA证书/ITAT证书/NVOCC证书/其它类型(8项)；目标 FILE_TYPES=营业执照/合同/资质证书/其他(4项) |
| 源有目标无=需补 | **上传文件控件**（目标配置面板无文件上传，纯 mock 元数据） |

## 7. 组件类型 / 交互方式

| 维度 | 源 | 目标 | 判定 |
|---|---|---|---|
| 弹窗形态 | 每子记录一个独立 el-dialog 组件 | 单一配置化 Modal（ALL_TABS 驱动） | 设计（已知） |
| 地区选择 | 级联 country/state/city/county 异步下拉 | 单 el-cascader REGIONS | 设计 |
| 文件/图片 | 收款/文件/设置均有上传 + 预览弹窗 | 无上传/预览（mock） | 源有目标无（受 mock 限制，标注） |
| 默认地址 | 表格 radio 触发 setDefaultAddress | isDefault + 操作列“设为默认” | 一致 |

---

## 一致性评分：更多附加信息 **72 / 100**

结构层面高度一致（6 Tab、客户隐藏收款/开票、CRUD+默认地址）。扣分集中在字段与枚举：
- 三处**选项枚举完全不同**（地址类型、设置类型、收款方式、文件类型）——需确认是否按源枚举回改；
- 我的设置缺失最多（证件类型/号码/照片、服务国家、是否公开、邮编、Tab 内搜索）；
- 收款信息缺整组银行明细字段；
- 联系信息缺 fax/alias/remark；
- 全表单必填规则普遍弱化（目标多数仅首字段必填）；
- 各表单上传控件缺失（mock 限制）。
开票信息字段对齐最佳。
