# 客户管理一致性核对（源 workProject2-jht Vue2 → 目标 Vue3）

- 源：`agent/workProject2-jht/src/views/organizers-management/customer-management/`
  - `index.vue`（列表）/ `addEditForm.vue`（新增编辑）/ `checkForm.vue`（审核）/ `personalForm.vue`（关联人员）/ `viewForm.vue`（查看）
- 目标：`src/views/organizers/Customer.vue`（列表+新增/编辑/查看/审核/修改归属集成于一文件）

> 背景约定：多租户/代理商层级（一级/二级代理商、公司类型 custTag、所属公司）为源项目 SaaS 特性，新项目单租户简化——以下涉及此类项标为【设计简化】，不计入需补。

## 1. 筛选项

源筛选（index.vue，从右侧工具条）：一级代理商 parentId【设计简化】、二级代理商 agentId【设计简化】、公司类型 custTag【设计简化】、所属公司 comId【设计简化】、客户类型 subtype、国家/地区 countryId、州/省 stateId、城市 cityId、（区/县 countyId 已注释）、状态 status、审核状态 audit、签署合同 signContract、公司名称 name。

目标筛选：公司名称 name、客户类型 subtype、国家 country、审核状态 audit、状态 status。

| 判定 | 项 | 说明 |
|---|---|---|
| 源有目标无=需补 | 签署合同 signContract 筛选 | 目标缺此筛选下拉（未签署/已签署/已注销） |
| 源有目标无=需补 | 州/省、城市 二级筛选 | 目标只有“国家”单级筛选；源可按 state/city 过滤 |
| 目标有源无 | —— | 无多余项 |
| 设计简化 | 一级/二级代理商、公司类型、所属公司 | SaaS 层级特性 |

## 3. 操作按钮 + v-permission 权限键

源按钮及权限键（逐字）：
- 头部：新增客户 `customerClientAdd`、批量导入 `customerClientExport`、查询 `customerClientQuery`
- 行操作：查看 `customerClientGet`、编辑 `customerClientUpdate`、修改归属（无权限键，条件 `custTag==='2' && custId==='280b587801744450a6b5aa3155c25e61'`）、审核 `customerClientReview`（且 `audit!=='1'`）、删除 `customerClientDel`（且 `audit!=='1'`）、更多 `customerClientMore`
- 其它：关联人员链接 `associatedPersonnel`、状态 switch `customerClientEnable`

目标：使用通用 `can('add'|'view'|'edit'|'del')`（usePagePerms，menuPerms+btnPerms 体系），**未逐字保留上述权限键**。

| 判定 | 项 |
|---|---|
| 字段差异 | 权限键未逐字对齐（项目既定 can() 设计，标注即可） |
| 源有目标无=需补(逻辑) | **删除按钮缺 `audit!=='已通过'` 守卫**：源仅未通过审核可删；目标恒可删 |
| 一致 | 审核按钮：源 `audit!=='1'` / 目标 `row.audit!=='已通过'`，语义一致 |

## 5. 审核弹窗（checkForm → 目标 audit Modal）

源 checkForm：只读展示 国家/地区、州省市区、公司/个人全称、主体类型；可编辑 公司类型 subtype、**添加来源 source**、合作期限 cooperate(daterange)、总分标识 branch、审核结果 audit（待审核/审核通过/审核拒绝）、备注 remark；企业只读 营业执照/成立日期/公司法人/证件信息/证照地址；**证件照片 3 张只读预览**（正面/反面/营业执照，type 2/3/1）。

目标 audit Modal：只读 公司名称/国家地区/主体类型/营业执照；可编辑 公司类型 subtype、合作期限 coopPeriod(select)、总分标识 branch、审核结果 audit；**证件照片 3 槽位可上传**（front/back/license，1MB，base64）；备注 remark。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **审核弹窗内“添加来源 source”可编辑项** 目标缺 |
| 源有目标无 | 审核只读展示：州省市区、公司简称、成立日期、公司法人、证件信息、证照地址（目标审核弹窗未回显） |
| 流程差异（重点） | **证件上传时机不同**：源在新增/编辑上传（必填校验），审核仅预览；目标新增/编辑无上传，改为**审核弹窗上传**。工作流反转，需确认设计意图 |
| 字段差异 | 合作期限 daterange vs select（同 §4） |
| 字段差异 | 审核结果文案：源“审核通过/审核拒绝” vs 目标“已通过/已拒绝”（AUDIT_STATUS） |
