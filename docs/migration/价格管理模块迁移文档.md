# 价格管理模块迁移文档（price-management）

> 源项目：`vue3-jht-admin`（Vue2 + `vue-property-decorator` class 组件 + Element UI + vxe-table + Sortablejs）
> 目标项目：`cross-border-logistics-admin`（Vue3 `<script setup>` + JS + Element Plus + Pinia + localStorage 持久化 mock）
> 迁移原则：逐字段一致性对齐；数据可造/可持久化，但不改原设计 UI、不改原交互、不增删内容；源隐藏/注释代码保留为注释不放开。
> 验收基线日期：2026-09-08　构建：`npm run build` ✅ 通过（18.07s，无报错）
> 降级约定（经确认）：vxe 二维价格矩阵统一降级为 el-table（同财务对账单方案）；Sortablejs 拖拽排序省略，行序由数据决定。

## 二、数据层（mock 基座）

统一文件：`src/api/modules/price.js`（替换原虚构骨架，约 755 行）。

### 共享字典（导出）
DISPATCH_LIST、PURPOSE_TYPE_LIST、PRICE_TYPE_LIST、SUBTYPE_LIST、CATEGORY_OPTS/CATEGORY_LABELS、ADDRESS_LABELS/ADDRESS_AXIS_LIST/ADDRESS_TYPE_LIST、AUDIT_STR_LIST、AUDIT_NUM_LIST、AUDITING_STATUS_LIST、EFFECT_STATUS_LIST、WAREHOUSE_EFFECT_LIST、LINE_STATUS_LIST、PRICE_TYPE_CAR（页内）、SUPPLIER_PRICE_TYPES；`SETTLEMENT_LIST` 复用财务模块（re-export）。

### 审核编码族（关键差异，勿跨页复用）
| 族 | 页面 | audit 字段 | 编码 | status/effective | 审核入参键 |
|----|------|-----------|------|------------------|-----------|
| STRING | 专线/快递/订舱 | `audit` | '0'待审/'1'通过/'2'拒绝/'3'审核中 | `status` '0'待生效/'1'生效中/'2'失效 | `audit` |
| NUMERIC | 卡派/拖车/报关 | `auditing` | 1待审/2审核中/3拒绝/4通过 | `effective` 1待生效/2生效中/9失效 → 显示态 `effectiveToStatus` | `status` |
| WAREHOUSE | 仓储 | `auditing` | 1/2/3/4（同上） | `effective` **1待生效/2生效中/3失效**（与他页不同） | `tag` |
| OUTSOURC | 外协 | `audit` | 1待审/2审核中/**4通过/3拒绝** | `status` 2生效中/1待生效/9失效 | `audit` |

### 工具函数
`lookup(list, id)`、`effectiveToStatus(e)`、`buildAxis(rows, loadType)`（STRING 矩阵列）、`buildNumAxis(rows)`（NUMERIC/外协矩阵列）。

### 资源 / 接口
- `chargeApi`（`price_charge`）、货物附加费资源：D 档简单 CRUD（list/add/update/remove/toggle）。
- `privateApi` / `expressApi` / `bookingApi`（STRING 档，`attachLineApi` 挂载）：getList / getById / save / audit / invalid / remove / history / effectiveBook / supplier。
- `carApi` / `trailerApi` / `customsApi`（NUMERIC 档，`attachNumApi` 挂载）：同上，audit 入参 `status`，invalid→effective 9。
- `warehouseApi`（`price_warehouse`，v3）：getList / getById / save / audit({tag,id,reason}) / invalid(effective 3) / remove / history / effectiveBook / standardPeriod / supplier({warehouseId})。收费项目 el-table + span-method。
- `outsourcApi`（`price_outsourc`，v3）：getList / getById / save / audit({audit,id}) / invalid(status 9) / remove / history。供应商为成本来源(fromCust)。
- 供应商聚合（无独立资源）：`supplierAggApiMap`（'05'→privateApi、'02'→bookingApi、'04'→warehouseApi、'01'→carApi、'06'→trailerApi、'03'→customsApi），供 Supplier.vue 按 priceType 取对应域资源只读投影。

### 选择弹窗数据源
getCountryOptions、getServiceOptions/getCarServiceOptions/getOutsourcServiceOptions、getAreaOptions、getChargeConfigOptions/getOutsourcChargeOptions、getContainerOptions、getVehicleOptions、getCabinetOptions、getCustomsOrgOptions、getCostItemOptions、getCustTypeOptions、getWarehouseOptions、getWarehouseChargeConfig、getSupplierList、getOutsourcSupplierOptions、getOutsourcAgentOptions、getDeliveryAreaOptions。

## 三、可复用组件族（`src/views/price/components/`）

- **PriceCardList.vue**：左侧 415px 卡片流面板，`#search` + `#card` 双插槽，箭头折叠 + 右键菜单（复制/查看/删除，`menu-deletable` 门控），分页；emits add/row-click/menu/update:page。

- **AgentPriceDialog.vue**：供应商报价浮层，`:fetch-supplier` prop + `.show({...})` 方法。

## 四、各页面对齐要点

### 1. 货物附加费 / 2. 收费配置（D 档）
- SearchBar + ProTable + Modal 简单 CRUD；启停 toggle；无审核流。

### 3. 专线价格（STRING，PrivateLine）
- 左卡片流（业务类型/目的国/审核状态 + 全部筛选 popover：交货区域全选/目的地类型/报价对象/价格标准/关税/派送方式/有效时间）。
- 右侧详情 + PriceMatrix；批量修改 popover；区间/区域配置（源 custType==='3' 才显示，mock 保留入口编辑态可点）。
- 审核弹窗：通过'1'/拒绝'2'；含"分公司同步审核通过"（category==='2' 且有未审分公司）。
- **保留注释**：区间/区域配置 custType 门控相关。

### 4. 快递价格 / 5. 订舱价格（STRING）
- 与专线同族，字段差异按侦察结果对齐（express/booking 各自 subtype/dispatch 候选）。

### 6. 仓储价格（WAREHOUSE，Warehouse）
- 左卡片流（仓库/审核状态/报价标准 + 有效时间 popover）；effective 1/2/3 状态标签。
- 右侧：仓库→拉收费项目配置 + 单位只读区；价格标准 标准/特殊（特殊取上级标准周期 refStandard）；关联代理商/客户穿梭框。
- **收费项目 el-table + span-method**：列0(收费项目)按 name 合并、列1(计费方式)按 name+type 合并，保留源 spanArr2"同名不同计费方式不 push"怪异行为；按车/按柜类型(type 5/6)无 cellValue 时价格只读。
- 参考价/标准价双表（custType 2 代理商显示参考价列 + 批量修改浮动）。
- 审核弹窗：通过4/拒绝3，入参键 `tag`；两步（1待审→2审核中）。
- **保留注释**：单票最低收费(floorPrice) 整块（模板项/表单/校验）；SYSTEM报价对象分支。

### 7. 卡派价格（NUMERIC，Car）
- 左卡片流（业务类型/服务 popover/审核状态/全部筛选：价格标准/计费方式/地址类型/有效时间）。
- 右侧详情 + PriceMatrix（Y=目的地或里程，X=车型/托数/重量&方数）；计费区间/里程 RangeConfigDialog；关联代理商穿梭框；单票最低收费。
- 审核入参键 `status`（2/4/3）；两步。

### 8. 拖车价格（NUMERIC，Trailer）
- Y=目的地 X=柜型；RelevanceTransfer 兼服务"设置目的地(y)"与"关联代理商(a)"两种 transferType；typeId '06'。

### 9. 报关价格（NUMERIC，CustomsClearance）
- Y=成本项目 X=海关；三种 transfer（成本项目 y / 海关 x / 关联代理商 a），`rebuildMatrix` 双轴缓存重建；typeId '03'。

### 10. 供应商价格（六域只读投影 + 审核，Supplier）
- 顶栏 priceType 下拉（'05'/'02'/'04'/'01'/'06'/'03'）切换挂载六域资源只读投影，**无新增/编辑/删除**，仅查看 + 审核。
- 卡片/详情字段按族抽象（str: lsc.value/period；warehouse: warehouseName/effective；num: service.value/status）。
- 审核按族分派编码（str→audit '1'/'2'；warehouse→tag 4/3；num→status 4/3），两步逻辑各族独立。

### 11. 外协价格（OUTSOURC，Outsourc）
- 左卡片流（业务类型/供应商/审核状态 + 全部筛选：服务/关税/派送/目的地类型）；供应商作为成本来源(fromCust)。
- 右侧详情 + PriceMatrix（Y=目的地地址，X 按 priceType 2重量/3体积/4整柜）；priceType '4' 隐藏计费配置(measureId)；所属公司(agentId) 仅 custType '0' 显示；无关联穿梭框、无供应商浮层。
- 计费区间/目的地 RangeConfigDialog；audit 4通过/3拒绝，入参键 `audit`；两步；status 2/1/9。
- **保留注释**：`destinationPort`、`status: 0`。

## 六、假设与偏差汇总（数据可造前提下）

| 页面 | 偏差/假设 | 原因 |
|------|-----------|------|
| 全部矩阵页 | vxe 二维矩阵 → el-table（PriceMatrix） | vxe 不可用，经确认降级（同财务对账单） |
| 全部矩阵页 | Sortablejs 拖拽排序省略 | 降级；行序由数据决定 |
| 专线/仓储 | 区间/区域/柜型配置为 RangeConfigDialog + ElMessage 桩 | 无后端；保留入口与交互 |
| 供应商价格 | 六域只读投影复用既有资源（supplierAggApiMap） | 源为六 price-*.vue 投影，避免重复造 6 套数据 |
| 各页 | 登录 custType 固定 mock（SYSTEM '0'/代理商 '2'） | mock 无登录态；分支按固定值走查 |
| 仓储 | 收费项目单位（重量/长度/货币）固定 KGS/CM/RMB | mock 无服务级单位源 |
| 外协 | 目的港(destinationPort) 保留注释未展示 | 源隐藏字段 |
| 通用 | 历史版本返回自身切片 | mock 无多版本存储 |
