# 财务管理模块迁移文档（financial-management）

> 源项目：`agent/workProject2-jht`（Vue2 + class 组件 + TS + Element UI + vxe-table）
> 目标项目：`cross-border-logistics-admin`（Vue3 `<script setup>` + JS + Element Plus + Pinia + localStorage 持久化 mock）
> 迁移原则：逐字段一致性对齐；数据可造/可持久化，但不改原设计 UI、不改原交互、不增删内容；源隐藏/注释代码保留为注释不放开。
> 验收基线日期：2026-08-17　构建：`npm run build` ✅ 通过（59.84s，无报错/警告级错误）

- `paymentApi`（`fin_payment`，16 行）：list / audit。

## 三、各页面对齐要点

### 1/2. 应收款 / 应付款（共用 InvoiceDetail.vue）
- 筛选：服务大类 / 状态 / 核销状态 / 发票时间 / keyWord+selectType（原单号1/开票企业2/提单号4/SO号5/柜号6）。
- 列表：原单号（02/06 显示 soNoList/billNoList）、状态、核销、发票日期、客户/开票企业、客户属性（仅应收）、货币、金额、创建/审核时间、截止付款、逾期天数。
- 行操作：编辑（ifVerify=0 && status≠3）、删除（ifVerify=0）、查看详情、审核（status≠1）。
- 详情：客户/服务类型/原单号/发票日期/发票类型/货币（@change 取汇率）/汇率/截止付款/备注 + 明细行子表（项目/说明/数量/单价/金额/本币金额）。
- 审核弹窗：通过1/拒绝2。
- **保留注释**：客户确认列、回滚/申请抵扣/申请调校 按钮。

### 3. 开票（OutInvoiceDetail.vue）
- 列表：客户/开票日期/审核状态/审核时间/本币总金额/是否税务开票；行操作 编辑（status≠3）/查看/审核（status≠1）/导出（服务大类=05）。
- 详情：全部/已选择 双模式；全部模式可勾选应收发票，已选择模式显示本币总金额 + 分币种金额。
- 校验：税务开票（ifBill=1）不能多币种。
- **保留注释**：发票编号 code 列、删除 按钮。

### 4. 收款单（CollectionDetail.vue）
- 双子表：关联回款（relationList）+ 核销发票（writeoffList）；软删 `tag='X'` + computed 过滤。
- 弹窗：选择客户 / 选择账号（getBankAccounts）/ 选择回款 / 选择发票 / 选择开票。
- 审核弹窗：通过1/拒绝2 → receiveApi.audit。
- **保留注释**：收款类型 payType（源 v-if=false）、通过/拒绝/重新提交 按钮。

### 5. 请款申请单（CashDetail.vue）
- 关联发票单子表；两步审核（status=0 先 audit→3 再开弹窗）。
- 弹窗：选择客户（供应商）/ 选择发票。
- **保留注释**：通过/拒绝/重新提交。

### 6. 付款单（PaymentDetail.vue）
- 双子表：冲销明细（请款申请单 tableData1）+ 关联发票（tableData2）。
- 弹窗：选择客户 / 选择请款申请单（getApprovedRequests，仅已通过）/ 选择发票；付款流水号 no-Chinese 校验；两步审核。

### 7. 对账单（CheckDetail.vue）
- 新增/编辑弹窗：年度 / 会计期间（getFiscalOptions）/ 类型 / 备注；关账（close）、删除受 ifClose≠1 限制。
- 详情：双表并排（回款明细 L / 银行数据 R）+ 统计条（笔数/合计/差额）+ 导入 + 自动对账 + 返回。
- **偏差（已在代码注释）**：源 vxe 拖拽对账 → 勾选配对（"对账 →" 按数量匹配且金额和相等时置 ifChecking=1，"取消对账" 清除）；导入为 ElMessage 桩（无后端）。

### 8. 会计期间
- 筛选年度；列表 会计期间/年度/起止/备注；新增编辑弹窗（年度→时间区间联动，disabledByYear 限制）；status=1 禁编辑/删除。
- **保留注释**：公司类型 / 所属公司 筛选。

### 9. 公司信用（7 弹窗，无独立详情页）
- 列表：名称/属性/预估成本/欠款/初始额度/可用信用/信用等级/是否签约/创建时间。
- 7 弹窗（均为真实交互，数据可造/持久化）：设置模板、查看要素（15 要素只读）、发票付款（getCreditInvoiceList 分页）、付款方式（paytypeList 子表增删）、设置标识（8 个开关）、编辑信用、申请调额。

### 10. 风险控制（RiskOrderDetail.vue）
- 筛选：风险类型 keyIndex（逾期/信用不足/冻结）/ 审核状态 / 运输方式 / keyWord。
- 列表：多列 + 风险标识 el-tag 组（逾期/信用不足/冻结/锁定）。
- 行操作：查看详情、审核（audit=0||3，两步）、更多下拉（冻结/申请解冻/解冻/特批发货/出库审核，按状态门控）。
- 详情：基本信息 + 单证/文件表（riskOrderApi.res.get）。
- **保留注释**：更多下拉的 编辑/删除/打印。

### 11. 专线订单（FinancialOrderDetail.vue）
- 9 统计卡（statistics）+ 主筛选栏 + 更多筛选抽屉（9 项）+ 宽表（多列横向滚动）。
- 行操作：查看详情。
- 详情：4 个 tab（商品信息 / 计量信息 / 验货信息 / 账单信息）。
- **保留注释**：源注释行操作按钮。

## 四、权限

所有页面接入 `usePagePerms().can(action)`，按钮 `:disabled="!can('add'|'edit'|'del'|'view'|'audit'|'export'|'close'|'config')"`。超管与未加载态放行；无权限操作真实置灰。

## 五、假设与偏差汇总（数据可造前提下）

| 页面 | 偏差/假设 | 原因 |
|------|-----------|------|
| 对账单 | 拖拽对账 → 勾选配对 | vxe-table 不可用 |
| 对账单 | 导入为 ElMessage 桩 | 无后端；spec 允许 |
| 通用 | 所属公司/comId 用空 options | mock 无公司选项源 |
| 收款/付款/请款 | 付款流水号 no-Chinese 校验用 `noChineseRule` | 复用 @/utils/validate |
| 收款单 | 结算账户列显示 `--` | 行模型无该字段 |
| 请款/付款 | 发票 code 缺失时回退 `FP{id}` | getSelectableOrders 行不含 code |
| 公司信用 | templateId/takeMethod 为持久化补充字段 | 源模型无对应字段 |
| 专线订单 | 更多筛选额外字段仅 UI 接入 | mock .list 只按 audit/type/keyWord 过滤 |
| 专线订单 | 验货信息 tab 用现有字段+el-empty | mock 无专用验货字段，保结构不造深度 |
| 风险/专线 | 数值码字段（wsIn/wsOut/measure 等）显示原值 | 无字典映射 |
