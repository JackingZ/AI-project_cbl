# 价格管理模块重建方案（price-management）

> 源项目：`agent/workProject2-jht/src/views/price-management`（Vue2 + class 组件 + TS + Element UI + vxe-table + Sortablejs）
> 目标项目：`cross-border-logistics-admin`（Vue3 `<script setup>` + JS + Element Plus + Pinia + localStorage mock）
> 迁移原则：逐字段一致性对齐；不改原设计 UI/交互；隐藏/注释代码保留为注释不放开；数据可造/可持久化；不增删内容。
> 已定基调（用户确认）：**价格矩阵用 el-table 降级**（对齐财务对账单方案，放弃 vxe 拖拽排序）；先产出本方案再定动手范围。

---

## 一、现状与差距

| 维度 | 目标现状 | 源项目实况 |
|------|----------|-----------|
| 页面文件 | 11 个 `src/views/price/*.vue`，各 ~60 行 | 11 个 index + 15 个子组件，合计约 4.7 万行 |
| 数据层 | `src/api/modules/price.js` 48 行虚构种子（name/country/price/days） | 每页独立后端接口 + 十几个联动接口 |
| 路由 | `src/router/index.js` L138-152 已注册 11 条（priceModule） | `router/modules/price-management.ts` 11 条 |
| 字段 | 完全虚构，与源无对应 | 复杂领域模型（价格矩阵/审核流/多币种/计费规则） |

**结论**：目标 11 页均为占位骨架，需按源整页重建 + 重构 mock 基座，与财务模块重建前状态一致。

路由 name 已定且需保持：PriceSurcharge / PriceCharge / PricePrivate / PriceExpress / PriceBooking / PriceWarehouse / PriceCar / PriceTrailer / PriceCustoms / PriceSupplier / PriceOutsourc。

## 二、页面分类（按架构复杂度分三档）

### A 档：卡片流 + 二维价格矩阵 + 审核流（6 页，最重）
专线、订舱、快递、卡派、拖车、报关。共同架构：
- **左右分栏**：左 `app-slide`（可折叠）= 筛选栏 + 卡片列表（非表格）+ 分页；右 = 内嵌详情/编辑区（`isRightShow`/`showAddForm` 控制），非路由跳转。
- **卡片**：审核状态圆点、服务名、报价对象、状态标签、有效期、业务类型标签；点击进详情，右键上下文菜单（复制/查看/删除）。
- **右侧价格矩阵**：X 轴（区间/柜型/海关）× Y 轴（地址/成本项目）二维表，可编辑单元格；参考价行（isSuperiorPrice）高亮只读。
- **业务流**：新增/编辑/保存/审核（两步：待审→审核中→通过/拒绝）/复制此版本/失效/历史版本切换/批量修改。
- **供应商报价浮层**（custType==='0'）：右下浮动图标 → 弹出只读供应商报价矩阵。
- **区间/区域配置弹窗** + **关联代理商/客户穿梭框**。

### B 档：卡片流 + 收费项目列表 + 审核（1 页）
仓储：右侧为 el-table（合并单元格 span-method）收费项目列表，含价格/最低收费输入列。

### C 档：聚合查看页（1 页）
供应商价格：左上下拉切换 6 个子报价类型（专线/订舱/仓储/卡派/拖车/报关），**纯查看 + 审核，无新增/编辑/删除**。复用 A/B 档矩阵结构。

### D 档：简单表单页（3 页）
- **货物附加费**（源为「商品类别」维护）：左树（懒加载）+ 右表 + 新增/编辑类别弹窗 + **设置附加费**二级弹窗（按国家配单价）。
- **计费配置**：重量/体积双 tab + 复杂动态表单弹窗（分泡规则/进位规则等）。
- **外协价格**：卡片列表 + 右侧 priceForm 价格矩阵（同 A 档但含目的地/派送/关税联动）。

## 三、降级与偏差策略（沿用财务模块已验证方案）

| 源实现 | 目标降级 | 依据 |
|--------|----------|------|
| vxe-table 二维矩阵 + 拖拽排序 | el-table 二维动态列，保留可编辑单元格；拖拽改为省略（矩阵行序由数据决定） | 用户确认；财务对账单同款 |
| vxe-modal 供应商报价浮层 | Modal + el-table 只读矩阵 | 保留浮动入口与交互 |
| 十几个 @focus 联动接口（getCountryList/getServiceList/getBscList…） | mock 选项源函数（复用 operation/organizers + 新增 price 选项源） | 财务 getBankAccounts 等同款 |
| el-transfer 穿梭框（关联代理/成本项目） | Element Plus el-transfer（原生支持，直接用） | 无需降级 |
| 导入 Excel（模板下载/上传） | ElMessage 桩 | 财务对账单导入同款 |
| Sortablejs 拖拽 | 省略 | 无 mock 后端排序语义 |
| 数值码字段无字典（loadType/addressType/priceType 等） | 按源写死映射表还原文案 | 逐字段对齐 |

**保真红线**：筛选项、列、表单字段、按钮（含状态门控）、弹窗、二级子系统入口一个不漏；源隐藏/注释代码保留为 HTML 注释。

## 四、mock 基座设计（重构 `src/api/modules/price.js`）

### 共享字典（导出，按源写死映射）
- `AUDIT_STR_LIST`（字符串审核：0待审核/1已通过/2已拒绝/3审核中，专线/订舱用）
- `AUDIT_NUM_LIST`（数值审核：1待审核/2审核中/3已拒绝/4已通过，卡派/拖车/报关/仓储用）
- `PRICE_STATUS_LIST`（生效状态：0待生效/1生效中/2已失效）
- `CATEGORY_LIST`（报价对象：0聚货通/1直客/2代理商/3供应商… 按各页规则）
- `LOAD_TYPE_LIST`（订舱 loadType：0散货/1包板/2整柜/3拼箱/4整车/5散货）
- `ADDRESS_TYPE_LIST`（卡派：0机场/1港口/2火车站/3海外仓/4私人地址）
- `DISPATCH_LIST`（派送方式：0卡派/1快递/2自提/3整柜直送/4到仓）
- `PURPOSE_TYPE_LIST`（目的地类型：0 FBA/1私人/2自有海外仓）
- `SETTLEMENT_LIST`（计费方式：0按重量…A按个数，复用财务同款可 import）
- `PRICE_TYPE_LIST`（计费方式：2按重量/3按体积/4按整柜）
- 单位映射：`UM_WEIGHT`（T/LBS/KGS/OZS）、`UM_LENGTH`（FT/M/CM/IN）、`UM_VOLUME`

### 资源 / 接口（defineMock）
每页一张主表 + 对应 CRUD/审核方法：
- `privateApi`（专线，含价格矩阵 rows/aAxis）
- `bookingApi`（订舱）、`expressApi`（快递）
- `carApi`（卡派，含 excelModelList）、`trailerApi`（拖车）、`customsApi`（报关）
- `warehouseApi`（仓储，收费项目列表）
- `supplierPriceApi`（供应商聚合，按 priceType 复用上述表的只读切片）
- `surchargeApi` + `surchargeCostApi`（商品类别树 + 附加费）
- `chargeApi`（计费配置，重量/体积双类型）
- `outsourcApi`（外协，含 priceForm 矩阵）

每个价格页方法集：`list / get / add / update / remove / audit / invalid / copy / history / batch`（按各页实际用到的子集）。

### 选择源函数（mock 联动，复用优先）
复用 operation.js（货币 CURRENCIES/区域）、organizers.js（供应商/客户/服务大类）；新增 price 专属：`getServiceOptions(type)`、`getCountryOptions`、`getAreaOptions`、`getContainerOptions`、`getChargeConfigOptions`、`getStandardPeriodOptions`、`getSupplierOptions`、`getWarehouseOptions`。

### 价格矩阵种子
按各页 X/Y 轴语义造 2-3 条示例矩阵（区间×地址 / 柜型×目的地 / 成本项目×海关），保证 el-table 动态列可渲染、单元格可编辑、可持久化。

## 五、可复用组件族（减少重复）

拟在 `src/views/price/components/` 下建：
- `PriceCardList.vue`：左侧筛选 + 卡片流 + 分页 + 右键菜单（A/B/C 档共用）。
- `PriceMatrix.vue`：el-table 二维动态列价格矩阵（可编辑/只读双模式，参考价行高亮）。
- `AgentPriceDialog.vue`：供应商报价只读矩阵浮层（Modal）。
- `RangeConfigDialog.vue`：区间/区域配置弹窗（one/two/three/four 模式）。
- `RelevanceTransfer.vue`：关联代理商/客户/成本项目穿梭框。
- 各页 index + Detail 组合调用上述组件，保持每页独有字段与门控。

权限统一 `usePagePerms().can(action)`，按钮 `:disabled="!can(...)"`；源无权限的供应商聚合页给审核按钮挂 can('audit')。

## 六、建议动手顺序（分批，每批可 build 验证）

1. **批 0（基座）**：重构 `price.js` mock 基座 + 共享字典 + 选择源 + 矩阵种子。
2. **批 1（D 档简单页）**：货物附加费、计费配置、外协 → 结构相对独立，先落地验证基座。
3. **批 2（可复用组件族）**：PriceCardList / PriceMatrix / AgentPriceDialog / RangeConfigDialog / RelevanceTransfer。
4. **批 3（A 档核心）**：专线、订舱、快递、卡派、拖车、报关（6 页，逐页复用组件族）。
5. **批 4（B/C 档）**：仓储、供应商聚合页。
6. **批 5**：全量 build + 迁移文档（对齐财务模块文档格式）+ 人工回归清单。

预计工作量约等于 3-4 个财务模块，需多轮完成。
