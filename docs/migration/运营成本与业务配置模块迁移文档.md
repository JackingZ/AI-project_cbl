## 二、数据层（mock 基座）

### `src/api/modules/operatingCost.js`（重建）

- **字典（导出）**：SERVICE_TYPE_LIST（服务大类 00~06）、SETTLEMENT_LIST（结算单位，字符串码 '0'~'9'/'A'，'A'=按个数）、GROUP_TYPE_LIST（项目组类型 '0'~'4'）。
- **内部映射**：SUBTYPE_MAP（服务大类→项目类型小类）、UM_MAP（结算单位→计量单位）。
- **下拉源**：getServiceTypeList、getCostitemTypeList({typeId})、getUmBySettlement({settlement})。
- **成本项目 `cost_projects_v2`**：getCostitemList（serviceTypeId 精确 + typeId 命中 types 数组 + name 模糊）/ saveCostitem / deleteCostitem。字段含 name/alias/serviceTypeId/serviceTypeName/types[{typeId,typeName}]/settlement/invoice/remark/ranging（仅 serviceTypeId==='04' 有值，布尔）。
- **成本项目组 `cost_groups_v2`**：getCostgroupList / saveCostgroup / deleteCostgroup。字段 name/type(字符串)/remark。
- **组-成员关联**：getCostmemberList / saveCostItems（内存 `_members` 按 costgroupId 存 costitemId 列表）；getCostList（穿梭左侧，按 serviceTypeId 过滤成本项目）。

### `src/api/modules/business.js`（重建）

- **字典/下拉源**：FEDEX_ID（导出）、EXPRESS_COMPANIES（getExpressCompany 返回 `{result}`）、COUNTRY_LIST（getCountryList）、STATE_MAP（getStateByCountry 返回 `{result}`，abbr 为值）、WORDS_MAP（getWordsList：ups_interface_api 接口路径 / LABEL_STYLE 标签格式）、CURRENCY_MAP（geCurrencyList 按 countryId 返回 `{result}`）、getCityByState（返回空 result，源城市下拉本就注释）。
- **快递接口 `biz_express_port_v2`**：getExpressPortList（参数 current/size + expressId/consignorCountryCode 精确，响应 `{records,total}`）/ getExpressPortById / addExpressPort / updateExpressPort(d.id) / deleteExpressPort([ids]) / changeExpressStatus({id}) 切换式翻转 ifEnable。字段含 returnerEntity 退货方子对象。
- **燃油费率 `biz_oil_rate_v2`**：getRateList（参数 current/size + portId，响应 `{result,total}`）/ updateRate（无 id 新增）/ deleteRate({ids})，按 portId 分组。

> **缓存陷阱**：全部资源用 `*_v2` key + version 2，避免旧占位种子 localStorage 缓存不重建。
