# 销售管理模块迁移文档（sales-management）

> 源项目：`vue3-jht-admin`（销售页仍为 Vue2 `vue-property-decorator` class 组件 + Element UI + `ve-histogram`(v-charts) + 旧 dialog 写法）
> 目标项目：`cross-border-logistics-admin`（Vue3 `<script setup>` + JS + Element Plus + Pinia + localStorage 持久化 mock）
> 迁移原则：逐字段一致性对齐；数据可造/可持久化，但不改原设计 UI、不改原交互、不增删内容；源隐藏/注释代码保留为注释不放开。
> 验收基线日期：2026-09-14　构建：`npm run build` ✅ 通过（33.17s，无报错）
> **关键差异**：销售模块**无审核流**（与价格/财务不同）；状态/可见性由身份码(custType/custSubtype/ifCustomer)+本地编辑态驱动。
> 图表决策（经确认）：源用 `ve-histogram`(v-charts，Vue2-only 且源项目未装未注册)，目标**安装 echarts@5.5.1 + vue-echarts@7.0.3 保真还原**（柱线混合/堆叠），非 Element Plus 降级。

## 二、数据层（mock 基座）

统一文件：`src/api/modules/sales.js`（替换原 30 行占位骨架）。

### 共享字典（导出）
BIZ_TYPE_LIST（空运0/海运1/铁路2/卡航4，快递3 注释保留）、AUDIT_LIST（待审0/审核中3/通过1/拒绝2）、ADDRESS_TYPE_LIST、CUSTOMS0_LIST、DELIVERY_WAY_LIST、PICK_LIST、PRICE_UNIT_LIST、COM_TYPE_LIST、MEASURE_METHOD_LIST（按重量2/按体积3）、VIEW_TYPE_LIST、SELECT_TYPE_LIST、PAY_STATUS_LIST、IF_LOADING_LIST、EXPRESS_NO_LIST、ORG_TYPE2_LIST、SWITCH_STATUS_LIST；兼容旧引用 STATUS_OPTIONS/PLAN_STATUS/COMMISSION_TYPES 保留。

### 工具函数
`lookup(list, id)`、`unitByBiz(biz)`（海运/铁路→CBM，空运/卡航→KG）。

### 资源 / 接口（7 API 族）
- `groupApi`（`sales_group`）：list / setStatus / saveGroup / remove（无审核，提交字段 `lscIds`）。
- `commissionApi`（`sales_commission`）：list（comId/subtypeId/lscId 筛选，countryId 强制不参与）/ save / getVersion / getLog；含 6 比例系数 + 阶梯区间 extentVoList + 版本(startTime~endTime) + 关联服务。
- `statApi`（`sales_stat`，v2）：list / statistics；宽表 40+ 字段（嵌套 custName/consignee/buyer/seller/lsc/express/measure/um/orderStatusLine）。
- `managerApi`（`sales_manager`，v2）：list / statistics / getMenuList（左侧状态菜单，number 占位）/ getStatusList（WS_IN/MEASURE/EXAMINE/CUSTOM_DECLARATION）/ getUserList（postType 0业务员/1财务/2客服）；与 statApi 共用 `buildOrderSeed` + `orderMatch`。
- `planApi`：company/depart/sales 三档独立资源（v2）+ listCompany/listDepart/listSales + getDistribut（company→分月合计表；depart/sales→周任务卡）。
- `agentPlanApi`（`sales_agent_plan`）：list / save / remove / getProviders（服务商多选，逗号拼接）。
- `boardApi`：getCard（4 卡 air/sea/train/car）/ getChart（区块2 公司/部门/员工排名）/ getGroupChart（区块3 服务组排名）/ getDetail（明细堆叠图）。

### 选择弹窗 / 下拉数据源
getCountryOptions、getCompanyOptions、getUnCompanyOptions、getDepartmentTree、getSalesmanOptions、getServiceSubtypeOptions（排除 id='3'）、getServiceOptions、getWarehouseOptions、getAgentOptions、getFiscalOptions、getWeekOptions。

## 三、组件族（`src/views/sales/components/`）

- **group-form.vue**：服务组新增/编辑弹窗(500px) + 嵌套关联服务穿梭框(960px)；业务类型 radio-button；提交字段 lscIds。
- **OrderExpressView.vue / OrderTrackingView.vue**：订单统计/业务员订单共用的 express(快递详情)/order-tracking(状态时间轴) 内嵌视图（`v-show` 切换，`ref.show(row)`）。
- **distribut.vue**：销售计划三态共用分配详情（company→分月合计表 + show-summary；depart/sales→周瀑布流任务卡）；单位空运/卡航=KG、海运/铁路=CBM。
- **plan-company.vue / plan-department.vue / plan-salesman.vue**：三档列表 + 统计卡 + distribut 内嵌切换；depart/salesman 保留注释的 comType 下拉。
- **agent-plan-form.vue**：发货计划新增/编辑表单(960px) + 服务商选择弹窗(1200px，多选)。
- **BillboardChart.vue**：看板柱线混合图（echarts core 按需 use）；计划量折线/完成量柱，蓝#409EFF/红#F56C6C，xAxis rotate -45 长名截断，barWidth 20px，tooltip 输出完成率%；`stack` prop 支持堆叠（detail 用）。
- **billboard-detail.vue**：服务组明细内嵌页（堆叠图 mock 硬编码 + 空 tableData，源 chartClick 注释故入口未启用）。

复用价格模块 `RelevanceTransfer.vue`（佣金关联服务穿梭框）。

## 四、各页面对齐要点

### 1. 销售计划（PlanDistribut）
- el-tabs 3 子页，tab 映射（非直觉）：first公司→CompanyPlan(salesCompanyPlan)、second部门→DepartPlan(salesDepartPlan)、third业务员→PersonPlan(salesMenPlan)；子页 v-if 懒挂载；默认 tab 按权限降序。
- 各子页：统计卡 + 列表 + distribut 内嵌详情（查看/编辑分配）。**无审核流**。

### 2. 销售看板（SalesBillboard，echarts）
- head-info 标题栏 + viewType radio（公司'1'/部门'2'/员工'3'，权限 v-if + 默认按权限降序）。
- 筛选第一组（实际生效）：parentId(custType '0')/comId/departId(tree-select, viewType '3')/year/period/week，联动 onXxx1。
- 4 统计卡（planXxx/actualXxx/完成率，actual<plan 蓝 num-min 否则橙 num-max）；svg-icon air/boat/train/car 降级为文字标签。
- Tab（业务类型，两区块共用）；单位 activeName ∈ ['1','2']→CBM 否则 KG。
- 区块2（公司/部门/员工排名）+ 区块3（服务组排名）：BillboardChart + 排名列表（前3 tips-top）。
- getPage 校验顺序：公司看板缺 parentId / 部门缺 comId / 员工缺 departId / 缺 period。
- **保留注释**：两个 `v-if="false"` 筛选组(selectForm/serviceForm) + onCompany2/3 等方法 + handleTab + chartClick(打开 detail)。

### 3. 服务组（ServiceGroup）
- 无独立筛选，仅新增 + 查询；列表 name/countryName/lscName/status(switch '1'/'0')。
- 开关：确认后 setGroupStatus，取消也刷新回滚。删除确认。
- group-form：名称/国家(filterable)/服务(穿梭框子弹窗)；subtypeId 排除 '3'；提交 lscIds；saleCreate '1' 门控（mock 固定 '0'）。**无审核流**。

### 4. 代理计划/发货计划（AgentBookingPlan）
- 列表（计划名称/编号/业务类型/目的国/服务商机构/计划量+单位/服务商/时间）+ 查看/编辑/删除。
- agent-plan-form：type '1'/'2'→CBM、'0'/'4'→KG 决定计划量单位；orgType2 船东1/空运2/铁路3；服务商 1200px 弹窗多选逗号拼接。**无审核流**。
- **保留注释**：源 addEditForm 338-351(radio 列)、576-581、617-623(rowClick 全注释)。

### 5. 佣金配置（CommissionConfig）
- 列表 + 4 弹窗：编辑/新增、查看、操作日志、关联服务(穿梭框)。
- 筛选 comId(custType '0')/subtypeId/lscId；countryId 源强制 undefined 不参与查询。
- 表单：6 比例系数(团队/客户/同事/托管客户/非正式 %) + measureMethod(按重量2/按体积3) + 版本(生效~失效) + 阶梯区间 extentVoList。
- 区间校验：完整、max>min、不重叠、连续。关联服务 tag==='1' 只读。**无审核流**。

### 6. 订单统计（OrdersStatistics）
- 3 视图 v-show 切换：main/express/order-tracking。
- 统计头：订单数量 + 6 图标统计。宽表 40+ 列（嵌套对象逐列渲染）。
- 更多筛选右抽屉(400px)：ifLoading/addressType/customs0/includeTax/deliveryWay(dispatchList 动态)/入库·计量·验货·报关状态/快递状态/付款状态多选。
- 当前状态列 el-link→order-tracking；快递单号「已出」→express。**审核为筛选项非行操作**，无行审核按钮。

### 7. 业务员订单管理（ManagerOrder）
- 左 200px 订单状态菜单树（handleSelect 空实现，number 占位）+ 右内容区。
- 统计头 5 图标（**label 与字段错位，按源保真**：总件数=paymentCount 等）+ 导出。
- 宽表（柜号/提单号两行、公司信用两行、应收金额账单+本币两行、账单已出/未出）。
- 关键字 + selectType(原单号1/柜号2/快递单号3/提单号4) + isVague 精准匹配开关 + 近30天默认下单时间。
- 更多筛选抽屉：同订单统计 + 所属业务员/财务/客服(getUserList postType 分类)。
- **保留注释**：报关方式列 customs1 两分支、typeList 快递'3'。
