# 服务配置模块迁移文档（service-configuration）

> 源项目：`vue3-jht-admin`（服务配置页仍为 Vue2 `vue-property-decorator` class 组件 + Element UI + toast-ui MarkdownEditor + 旧 dialog 写法）
> 目标项目：`cross-border-logistics-admin`（Vue3 `<script setup>` + JS + Element Plus + Pinia + localStorage 持久化 mock）
> 迁移原则：逐字段一致性对齐；数据可造/可持久化，但不改原设计 UI、不改原交互、不增删内容；源隐藏/注释代码保留为注释不放开。
> 验收基线日期：2026-09-14　构建：`npm run build` ✅ 通过（24.23s，无报错）
> **关键差异**：服务配置模块**全程无审核流**，所有实体仅启用/禁用两态。
> **编码陷阱**：`status` 开关——快递用【数字】`1/0`；其余全部页面（含专线/服务组）用【字符串】`'1'/'0'`。`addressType`/`subtypeId`/`purposeType` 各页含义不同，逐页对照。
> **Markdown 降级**（经确认）：源用 toast-ui MarkdownEditor（目标未安装），专线运输条款降级为 `<el-input type="textarea" :rows="10">`，字段仍为 `terms` 字符串。

## 二、数据层（mock 基座）

统一文件：`src/api/modules/service.js`（替换原占位骨架，约 740 行）。基座 `defineMock(key, seedFn, searchKeys, version)`；缓存陷阱：seed 结构变更须 bump version，全部新资源用 `svc_*_v2` key。

### 共享字典（导出）
TYPE_ID、EXPRESS_SUBTYPE_LIST、CUSTOM_EXPORT_LIST、TRUCK_SUBTYPE_LIST、TRAILER_ADDRESS_TYPE_LIST、CONTAINER_TYPE_LIST（拼箱0/整柜1）、COVER_TANK_LIST（否0/是1）、ORG_TAG_LIST（美森1/以星2/快线3/其他4）、PURPOSE_LIST、PURPOSE_TYPE_LIST（FBA0/私人1/自有海外仓2）、DISPATCH_LIST（数组，index 映射派件方式）、CATEGORY_LIST、PRICE_TYPE_LIST、STATUS_LIST、SUBTYPE_LIST（空运0/海运1/铁路2/快递3/卡散4）、CURRENCIES、PRODUCTS、SUPPLIERS、AGENTS、EXAMINE_LIST。

### 共享下拉数据源
getCountryList、getCurrencyList、getStateByCountry、getAllAreaList(type,countryId)、getRegionList(countryId)、getPortList(countryId,type)、getFbastoreList(countryId)、getContainerList、getServiceSubtypeList(typeId)（typeId'01'→整柜/拼箱；其余→通用小类）、getProductList、getAgentOptions、getSupplierOptions、getExamineList、getWordsList(type)（server_terms 供服务条款）、getCostgroupList（计费发票费用组）、getEscList（打单快递服务）、getCscList（起运港报关）、getKscList（起运港卡派）、getDeliveryList（交货区域，源已注释保留数据源）。

### 资源 / 接口（7 API 族）
- `expressApi`（`svc_express_v2`）：list / save / changeStatus（status **数字**）；attachAgent；关联代理商/排除仓库/目的地区域/计费/邮编分区子接口。
- `bookingApi`（`svc_booking_v2`）：list / save / changeStatus（切换式）；attachAgent + attachPrice；航线服务商按 bsId 存。
- `truckApi`（`svc_truck_v2`）：list / save / changeStatus；attachAgent；设置车型/区间 + 目的地 + 服务组合（truckSvcGroup）。
- `trailerApi`（`svc_trailer_v2`）：list / save；attachAgent；私人地址行内编辑 + 其它类型穿梭 + 关联柜型 + 服务组合（trailerSvcGroup）。
- `customsApi`（`svc_customs_v2`）：list / save / changeStatus；attachAgent；成本项/报关配置。
- `warehousingApi`（`svc_warehousing_v2`）：list / save；attachAgent。
- `privatelineApi`（`svc_privateline_v2`）：list（12 项筛选）/ getById / save / changeStatus（status **字符串**）；attachAgent + attachPrice；`getAgents` / `getPorts(countryId,type,name)` / `getComplicatedList({subtypeId,...})`；`savePriceConfig` 包装——xy==='Y' 翻 ytag，xy==='X' 翻 xtag。
- `privatelineSvcGroup`（`svc_privateline_group`）：makeSvcGroup（query{subtypeId}/save/remove）——专线服务组合。
- `lineGroupApi`（`svc_line_group_v2`）：list / save / changeStatus / getItems（回显组内已关联服务）——专线服务组。

### 通用挂载器
`attachAgent(api)`：`_agents{}` + getAgentById / saveAgent（按 serviceId 存已选 id 列表）。
`attachPrice(api)`：`_price{}` + getPriceConfig(serviceId,xy) / savePriceConfig。
`makeSvcGroup(key)`：服务组合通用资源（typeId/subtypeId 筛选）。

## 四、保真对照要点（验收清单）

1. **无审核流**：全模块仅启用/禁用两态，无「待审/审核中/通过/拒绝」。
2. **status 编码**：快递数字 1/0；其余（含专线、服务组、服务组合）字符串 '1'/'0'。开关守卫：`olds===news` 直接 return，取消回滚 `loadData()`。
3. **专线三态视图**：源 `addEditForm` 字符串三态完整保留，非布尔量。
4. **isType 价格弹窗**：1 地址/2 区间/3 柜型/4 重量，四态与源一一对应；rangeValidate 四条规则齐全。
5. **源注释代码全部以 HTML/JS 注释保留不放开**：关联服务编码 select、地区、交货区域、计费快递 escId、目的港筛选下拉、商品属性筛选、方数范围 sections2、交货区域列。
6. **Markdown 降级**：仅渲染方式变化（textarea），字段/交互/保存不变。
7. **数据可造**：全部走 localStorage 持久化 mock，无真实后端；下拉/穿梭数据源均由 mock 供给。
