# AI-project_cbl

### 基于claude code完成产品经理的可视化界面交付，需求文档生成，结构图流程图绘制等技能，提高产品经理的产出效率和质量。

### 这是一个跨境物流公司的完整业务项目。

### 基于前端vue技术和本地mock数据实现业务操作，不依赖后端，浏览器清理会导致数据清除影响展示。

### 记录对话提示词，且归纳日志，便于后续追踪，并加入git管理仓库。

## GitHub Pages 部署

推送到 `main` 后，GitHub Actions 会运行 `npm ci` 和 `npm run build`，再将 `dist/` 作为 Pages 站点发布。`dist/` 是编译结果，无需提交到仓库。

首次启用时，在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。发布完成后访问 `https://jackingz.github.io/AI-project_cbl/`，可在 **Actions** 页面查看构建和部署状态。
