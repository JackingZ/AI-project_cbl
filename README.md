# AI-project_cbl

## GitHub Pages 部署


### 基于claude code完成产品经理的可视化界面交付，需求文档生成，结构图流程图绘制等技能，提高产品经理的产出效率和质量。

### 这是一个跨境物流公司的完整业务项目。

### 基于前端vue技术和本地mock数据实现业务操作，不依赖后端，浏览器清理会导致数据清除影响展示。

### 记录对话提示词，且归纳日志，便于后续追踪，并加入git管理仓库。



补充：

仓库的 Pages 来源设置为 `Deploy from a branch`、`main`、`/(root)`。根目录的 `index.html` 会跳转到 `dist/`，页面资源也从 `dist/assets/` 加载。

修改源码后运行 `npm run build`，将生成的 `dist/` 文件与源码一起提交并推送到 `main`。访问地址为 `https://jackingz.github.io/AI-project_cbl/`。
