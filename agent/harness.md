一、本项目固定技术栈，全程不允许更换：
1. 构建工具：Vite
2. 框架：Vue3 <script setup> 语法糖，禁止选项式API
3. UI组件库：Element Plus，按需引入，所有表单、表格、弹窗、按钮、分页全部使用官方组件，禁止手写原生控件
4. 样式：全局统一使用scss，全局变量存放 src/assets/style/vars.scss，页面仅允许使用全局变量，禁止硬编码色值、字号、间距
5. 路由：vue-router 4，统一管理 src/router/index.js，所有页面路由必须在此文件注册
6. 请求：axios统一封装 src/api/request.js，模拟接口统一放在 src/api/modules/，所有页面接口调用统一导入，不重复写请求逻辑
7. 状态：简单状态用localStorage，复杂全局状态用pinia，统一存放src/store
8. 页面适配：PC端优先，宽度断点1200px、1440px，自适应布局

二、强制项目目录结构，所有新增文件必须放到对应文件夹，不得随意新建文件夹：
src/
├── assets/          # 静态资源、全局scss变量、图片
│   └── style/
│       ├── vars.scss  # 全局色值、字号、间距、圆角变量
│       └── global.scss # 全局重置样式
├── components/     # 全局公共组件（所有页面复用）
│   ├── Layout/     # 侧边栏、顶部导航、面包屑、页面容器
│   ├── Common/     # 全局弹窗、通用表单、空状态、卡片、搜索栏
│   └── Table/      # 通用表格封装（分页、筛选、批量操作）
├── router/
│   └── index.js    # 唯一路由文件，所有页面必须在这里注册路由、配置菜单名称、面包屑
├── views/          # 所有业务页面存放目录，按业务模块分文件夹
│   ├── order/
│   │   ├── List.vue  # 订单列表
│   │   ├── Add.vue   # 新增订单
│   │   └── Detail.vue # 订单详情
│   ├── user/
│   └── dashboard/
├── api/            # 接口统一封装，分业务模块
├── store/          # 全局状态
├── utils/          # 工具函数：表单校验、时间格式化、通用方法
└── App.vue / main.js # 入口文件

约束规则：
1. 所有业务页面统一放入views下对应业务文件夹，禁止散落在根目录
2. 公共弹窗、导航、表格全部抽离到components全局复用，页面内禁止重复写相同UI代码
3. 新增页面必须同步更新router/index.js，补充路由path、name、菜单标题、面包屑层级
4. 所有页面跳转使用this.$router / useNavigate，硬编码跳转地址统一从路由文件读取
5. 所有数据都做持久化存储和增删改查

三、路由统一约束，实现完整页面跳转串联：
1. 路由文件唯一：src/router/index.js，不允许分散定义路由
2. 路由规范：
   - 列表页路径：/模块/list 例：/order/list
   - 新增页路径：/模块/add
   - 详情页路径：/模块/detail/:id
3. 侧边栏菜单自动读取路由配置，新增路由必须同步配置菜单显示名称、图标
4. 面包屑自动根据路由层级生成，无需页面单独写
5. 弹窗内跳转、按钮跳转全部使用路由name/path，禁止写死url
6. 完整业务流程链路记录：
   例：首页dashboard → 订单列表/order/list → 新增订单/order/add 提交返回列表 → 列表点击详情/order/detail
   AI开发每个页面时，自动实现上述跳转逻辑
7. 未登录、权限拦截统一在路由守卫处理，所有页面共用一套逻辑

四、全局UI与代码强制约束，保证全项目视觉、交互统一：
1. 样式约束
   - 所有颜色、字号、圆角、阴影、内外边距，全部引用src/assets/style/vars.scss全局变量，禁止页面内写 #fff、font-size:14px 这类硬编码
   - 统一组件尺寸：按钮高度、输入框高度、卡片圆角、表格行高严格遵循UI规范
   - 页面统一使用 Layout 全局容器组件，自带统一边距，禁止每个页面自定义外边距
2. 交互统一约束
   - 全局弹窗统一调用 components/Common/Modal，统一遮罩、关闭按钮、弹窗层级
   - 表单校验规则统一封装utils/validate.js，复用正则、必填提示文案
   - 加载状态、骨架屏、空数据、报错提示统一全局组件，每个页面直接引入使用
   - hover、点击、禁用态样式全部在全局变量定义，页面不单独写hover样式
3. 代码复用约束
   - 重复逻辑（分页、删除确认、导出、批量操作）抽成全局工具/公共组件，禁止每个页面重复复制代码
   - 页面只写当前业务独有逻辑，公共能力全部复用全局封装内容
4. 禁止行为：
   - 禁止在单页面scoped中定义全局通用样式
   - 禁止重新封装基础按钮、输入框、表格组件
   - 禁止创建独立路由文件、独立请求封装
