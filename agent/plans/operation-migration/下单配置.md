# 下单配置 order-type/ → src/views/operation/OrderType.vue

## 源页结构
- head-info title=下单配置；单页列表 + 分页；无侧滑/tab。顶部右侧行内筛选。
- 弹窗1(isRelevanceShow, 960px)：内嵌两子组件，isAdded 切换 addedServiceRelevance/additionalServiceRelevance。
- 弹窗2(isNameShow, 600px append-to-body)："服务名称"表单。
- 子组件 addedServiceRelevance.vue(关联服务项目)：独立表格+分页+新增/编辑弹窗(append-to-body 600px)。
- 子组件 additionalServiceRelevance.vue(关联附加服务)：同上，字段略少。

## 筛选项
- 服务大类 el-select serviceTypeId placeholder=服务大类 filterable clearable @focus getServiceList(getServiceTypeList({custType:'1'}), label=name value=id) width130。
- 下单配置 el-input name，slot prepend 文字"下单配置" width280 placeholder 请输入。
- 查询：v-permission="['ploQuery']" @click queryAll(1)。

## 表格列
- serviceTypeName 服务大类
- name 下单配置
- 服务名称 width120：按钮，:disabled="!$checkPermission(['ploServiceName'])" @click setServiceName
- 服务项目 width120：按钮，:disabled="!$checkPermission(['ploServiceProject'])" @click setAddedService
- 附加服务 width120：按钮，:disabled="!$checkPermission(['ploAdditionalItems'])" @click setAdditionalService
- remark 备注
- updateTime 最后更新时间 width170

## 操作按钮
- 无行内编辑/删除；操作通过三个列按钮触发弹窗。权限键：ploServiceName/ploServiceProject/ploAdditionalItems($checkPermission 控 disabled)。
- 查询：ploQuery。

## 新增/编辑表单字段
- 弹窗2(服务名称)：serviceId el-select label=服务名称，选项按 serviceTypeId 走 7 接口(getEsc/Ksc/Bsc/Csc/Ssc/Lsc/Tsc List)。required change「请选择服务名称」。
- 子组件 addedServiceRelevance 弹窗(服务项目)：itemId(select getAddedList, required change)/attachment(radio 是否上传附件 false否/true是, required change)/required(radio 附件是否必传, v-if=attachment, required change)/type(radio 服务标识 0标准/1增值, required change)。
- 子组件 additionalServiceRelevance 弹窗(附加服务)：itemId(select getAdditionList, required change)/attachment(radio)/required(radio v-if attachment)/type 硬编码'2'，无服务标识控件。

## 详情/次级弹窗/子页
- addedServiceRelevance 表格列：itemName/attachment(是/否)/required(是/否)/type(标准服务/增值服务)/操作(编辑、删除 $confirm)。分页。
- additionalServiceRelevance 表格列：itemName/attachment/required/操作(无服务标识列)。
- 两子组件均通过父 $refs.xxx.init(obj) 初始化。

## 目标页现状
- 通用 CRUD：筛选 name/bizType/status；列 name/bizType/status/createTime；Modal 表单 name/bizType(select)/status。无权限键、无服务大类、无三个关联弹窗、无服务名称弹窗。

## 差异
- 需补：服务大类筛选 select(focus 加载)；下单配置 prepend 输入框；ploQuery 权限键；表格替换为 serviceTypeName/name/服务名称按钮列/服务项目按钮列/附加服务按钮列/remark/updateTime，三按钮列 $checkPermission disabled；服务名称弹窗(7 接口按类型取选项)；两关联子组件(addedServiceRelevance、additionalServiceRelevance)含各自表格/分页/新增编辑弹窗/校验。
- 需删：bizType 字段与 Modal 新增/编辑(源主表无新增/编辑主记录，仅关联维护)。
- 字段映射：name→name；bizType/status 源无对应。
- 工作量：极大。
