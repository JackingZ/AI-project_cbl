# 货柜管理 container-management/index.vue → src/views/operation/ContainerManagement.vue

## 源页结构
- 单页 head-info(货柜管理) + app-panel。左上"新增柜型"，右上筛选。el-table + 分页。单个 el-dialog 新增/编辑柜型(900px)。无地区/无穿梭。单位来自字典。

## 筛选项
- 关键字 el-input clearable placeholder=车型名称关键字(源文案沿用) selectValue.name。
- 查询：v-permission="['queryCurrency']"(注意：权限键是 queryCurrency 非 container) @click queryAll(1)。无国家筛选、无重置。

## 表格列
- 柜型名称 prop=name
- 英文名称 prop=alias
- 柜长 length formatterUnit(umLengthList,'umLength') min100
- 柜宽 width formatterUnit(umLength) min100
- 柜高 height formatterUnit(umLength) min100
- 装载体积 volume formatterUnit(umVolumeList,'umVolume') min100
- 最大限重 loadLimit formatterUnit(umWeightList,'umWeight') min100
- 操作 fixed=right width160：编辑/删除
（无座位数、无国家列）

## 操作按钮（权限键）
- 新增柜型：addContainer icon=circle-plus-outline @click addCar(firstInput.focus)。
- 查询：queryCurrency。
- 编辑：editContainer @click editVehicle。
- 删除：deleteContainer，$confirm('请确认是否删除该条数据?','温馨提示',warning) → deleteContainer。

## 新增/编辑表单字段（label-width100, inline 各50%）
- 货柜名称 prop=name el-input maxlength50 (ref firstInput)；required blur「货柜名称不能为空」
- 英文名称 prop=alias maxlength50；required blur + validator 禁中文
- 长度单位 prop=umLength el-select(measurement_type) @change onLength；required change
- 体积单位 prop=umVolume el-select disabled(VOLUME_TYPE 联动)；required change
- 重量单位 prop=umWeight el-select(weight_type)；required change
- 长度 prop=length el-input-number controls=false min0 max9999 precision2；required blur
- 宽度 prop=width min0 max9999 precision2；required blur
- 高度 prop=height min0 max9999 precision2；required blur
- 装载体积 prop=volume min0 max99999 precision2；required change
- 最大限重 prop=loadLimit min0 max99999 precision2；required blur
- 保存 saveContainer（无 countries）。无座位数、无地区。

## 目标页现状
- SearchBar(货柜名称/规格 CONTAINER_SPECS/状态) + ProTable + Modal。列 name/containerNo(柜号)/spec(规格)/status/createTime。表单 货柜名称/柜号/规格/状态。默认 spec='20GP'。无 v-permission。

## 差异
- 需补：单位字典 umLength/umVolume/umWeight + onLength 联动、尺寸字段 length/width/height/volume/loadLimit(min/max/precision)、英文名称 alias(中文校验)、表格 formatterUnit 带单位、权限键 addContainer/queryCurrency(注意此键)/editContainer/deleteContainer、新增 firstInput 聚焦。
- 需删/确认：规格 spec 枚举 CONTAINER_SPECS(源无 spec)、柜号 containerNo(源无)、status 开关、createTime 列。
- 字段映射：目标(name/containerNo/spec/status) 与源(name/alias/尺寸+单位) 仅 name 对应。
- 工作量：极大。
