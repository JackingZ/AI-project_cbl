# 服务大类 service-genara/ → src/views/operation/ServiceGenara.vue

## 源页结构
- index.vue 主列表页(无树/无tab)。head-info title=服务大类。顶部工具行(新增+筛选) + 表格 + 分页 + 2 弹窗：新增/编辑服务大类(600px)、服务类型子弹窗(600px 标题`服务类型【typeName】`，内嵌 subType.vue)。
- subType.vue(服务类型子页，ref+init(row) 传入 typeId/typeName)：列表 + 分页 + 新增/编辑服务类型弹窗(600px append-to-body，含"计费区间"动态行)。

## 筛选项
- 公司类型 el-select selectValue.type clearable width200：供应商=3/代理商=2/客户=1。（data 中 type 初值为 []，queryAll 用 .includes 判断→params.supplier/agent/customer=true）
- 服务大类 el-input selectValue.name maxlength20 width300，prepend 文字"服务大类" placeholder 请输入。
- 查询：v-permission="['categoryQuery']" @click queryAll(1)。

## 表格列
- 服务大类 prop=name min120
- 供应商 prop=supplier width120：typeFilter(row,'3')→row.supplier?'√':'--'
- 代理商 width140：typeFilter(row,'2')→row.agent?'√':'--'
- 客户 width140：typeFilter(row,'1')→row.customer?'√':'--'
- 排序值 prop=sort width150
- 添加类型 width120：按钮"服务类型"，:disabled="!$checkPermission(['categoryStatistics'])"，@click setSubType(row)(打开子弹窗+subType.init)
- 添加时间 prop=createTime width180
- 操作 width100 fixed=right：编辑(categoryUpdate)。无删除。
- 表格高度 calc(100vh-313px) size=10。

## 操作按钮（权限键逐字）
- 新增服务大类：categoryAdd，type=text icon=circle-plus-outline @click addType(focus firstInput)。
- 查询：categoryQuery。
- 服务类型(列内)：$checkPermission(['categoryStatistics'])。
- 编辑：categoryUpdate。
- （子页 subType 内新增/编辑无权限键，删除被注释）

## 新增/编辑表单字段（服务大类弹窗 600px, label-width90）
- 服务大类 prop=name：el-input(ref firstInput) maxlength20。required blur「服务大类不能为空」
- 公司类型 prop=type：el-select multiple clearable，供应商=3/代理商=2/客户=1。required=false change「请选择关联公司」
- 排序值 prop=sort：el-input-number(:controls=false min0 max9999 step1 step-strictly)。required blur「排序值不能为空」
- 保存 saveConfirm：type 数组→supplier/agent/customer 布尔(includes '3'/'2'/'1')→saveType；editType 回填按 customer/agent/supplier 反推 type 数组。

## 详情/次级弹窗/子页（subType.vue 服务类型）
- 子弹窗顶部 新增服务类型按钮(type=text 无权限键 @click addSubType)。
- 服务类型列表(height450)：服务类型 name / 逾期计费 overdue width100(0按重量/1按体积/2按比例) / 计费区间 overdueCharges width180(拼 `lower-upper, `) / 操作 width100(编辑；删除注释)。分页 size10。
- 新增/编辑服务类型弹窗(600px append-to-body, label-width90)：
  - 服务类型 prop=name：el-input(ref firstInput) maxlength20。required blur「服务类型不能为空」
  - 逾期计费 prop=overdue：el-select(0按重量/1按体积/2按比例)。required change「请选择逾期计费」
  - 计费区间 prop=overdueCharges：动态行 v-for，每行 3 个 el-input-number(下限 lower/上限 upper/单位金额 amount，:controls=false min0 max999999；lower/upper step1 step-strictly，amount :precision=2) + 行尾图标(index0 加号 addRangeData，其余 减号 deleteRangeData)。required blur「计费区间不能为空」
  - 保存 saveConfirm 业务校验：每行 lower>=0 && upper && amount 完整(否则"请完整填写计费值&单位金额")；upper<=lower 报"下限值不能大于等于上限值"；区间重叠报"区间范围不能重叠"→saveSubtype(带 typeId/typeName)。
- API：getServiceTypeConfigList/saveType(主)、getServiceSubtypeConfigList/saveSubtype/deleteSubtype(子)。

## 目标页现状
- SearchBar：大类名称/状态。列：name/code/remark/status(switch)/createTime。表单：大类名称/编码/备注(textarea)/状态(radio)。仅 name 必填。无公司类型多选、无排序、无服务类型子弹窗与计费区间。

## 差异
- 需补：公司类型多选筛选/表单(供应商3/代理商2/客户1)+supplier/agent/customer 布尔映射；供应商/代理商/客户 三列 √/--；排序值 sort+列；服务类型子弹窗+subType.vue(列表+分页+计费区间动态行+三段业务校验+overdue 枚举)；权限键 categoryAdd/categoryQuery/categoryUpdate/categoryStatistics；API getServiceTypeConfigList/saveType/getServiceSubtypeConfigList/saveSubtype。
- 需删/确认：status 列+toggle、code、remark、状态筛选、行内删除(源大类无删除)。
- 字段映射：name→name；源 sort/supplier/agent/customer/type 目标全缺；目标 code/remark 源无对应；源无 status 概念。
- 工作量：大（主页中等，子组件计费校验偏重）。
