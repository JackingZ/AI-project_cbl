# 验货配置 examine-config/ (index.vue + addEditForm.vue) → src/views/operation/ExamineConfig.vue

## 源页结构
- index.vue：head-info(验货配置) + app-panel。右上：左浮"新增配置"，右侧筛选。el-table + 分页。
- 新增/编辑：el-dialog(1000px) 内嵌子组件 addEditForm.vue(ref addModel, props type-list/is-edit, events @load @cancel)。编辑时 $nextTick 调 addModel.show(row)；取消调 addModel.reset()。子组件含 20+ 表单项。

## 筛选项（index.vue）
1. 验货方式 el-select clearable filterable placeholder=验货方式 selectValue.type：按产品=0/按比例=2(本地)。
2. 验货配置名称 el-input maxlength20 placeholder=验货配置名称 selectValue.name。
- 查询：v-permission="['lnspectionConfigQuery']"(注意拼写 lnspection 首字母 l) @click getTableData(1)。

## 表格列（index.vue）
- 验货配置名称 prop=name min130
- 验货方式 prop=type width120 slot：0→按产品/2→按比例
- 验货程度 prop=degree :formatter=formatExamineType(degree.split(',') 映射 typeList name 拼接) min200
- 抽箱方式 prop=pick width120 slot：0→随机/1→指定
- 是否验证尺寸 prop=size width150 slot：size?是:否
- 操作 fixed=right width180：编辑/删除

## 操作按钮（权限键）
- 新增配置：lnspectionConfigAdd icon=circle-plus-outline @click addExamine。
- 查询：lnspectionConfigQuery。
- 编辑：lnspectionConfigUpdate @click editExamine(打开弹窗 + addModel.show)。
- 删除：lnspectionConfigDel，$confirm('请确认是否删除该条数据?','温馨提示',warning) → deleteExamineConfig。
- typeList 本地固定(验货程度选项)：纯电=0/带电=1/强磁=2/弱磁=3/液体=4/粉末=5。

## 新增/编辑表单字段（addEditForm.vue, label-width150, inline 各49.5%）
1. 验货配置名称 prop=name maxlength20；required blur「验货配置名称不能为空」
2. 验货方式 prop=type el-select clearable filterable：按产品=0/按比例=2，@change form.ratio=undefined；required:false change
3. 验货比例 prop=ratio el-input，append "%"，v-if="form.type==='2'"；required:false + validator numberValidate /^([1-9]\d{0,1}|100)$/「比例为1-100的正整数」
4. 验货程度 prop=degreeArr el-select multiple collapse-tags clearable(typeList)；required:false change
5. 验货图片保留 prop=retain el-select clearable(imgTime 本地 1~12个月 id1-12)；required:false change
6. 需检验项 prop=itemsArr el-select multiple collapse-tags(examineList 本地：售后地址=0/厂商信息=1/生产批号=2/五国说明书=3/包装五国文字=4)；required:false change
7. 查验MadeInChina prop=micArr el-checkbox-group(micList：外箱=0/内件=1，checkbox :label=item.name)；required:false change
8. 外箱查验 prop=boxArr el-checkbox-group(checkList：原产地=0/工厂信息=1)；required:false change
9. 产品查验 prop=goodsArr el-checkbox-group(checkList 同上)；required:false change
10. 抽箱方式 prop=pick el-radio-group：随机=0/指定=1(默认'0')；required:false change
11. 是否验证订单尺寸 prop=size el-radio-group：否=false/是=true(默认 false)；required:false
12. 是否查验超重标 prop=overweight radio false/true；required:false
13. 是否查验带电标 prop=electrified radio false/true；required:false
14. 是否查验危险品标 prop=danger radio false/true；required:false
15. 是否允许编织袋 prop=bag radio false/true；required:false
16. 是否允许捆绑 prop=binding radio false/true；required:false
- 隐藏/派生字段：mic/degree/items/goods/foreigns(字符串)、custId/custName、id。
- show(row)：拆分 goods/foreigns/mic/degree/items 逗号串回填 *Arr。
- submit：*Arr 映射回 index 串(goods=checkList index、foreigns=checkList index、mic=micList index、degree/items=id join)，saveExamine；成功 emit cancel+load。
- footer：取消(@cancel)/确定(@submit)。

## 详情/次级弹窗/子页
- 子组件 addEditForm.vue 即弹窗内容(非独立路由)。父子通过 ref 方法(show/reset) + 事件(load/cancel) 通信。

## 目标页现状
- 单文件 SearchBar(name/mode EXAMINE_MODES/status) + ProTable + Modal，无子组件。列 name/mode/ratio(抽检比例%)/status/createTime。表单仅 4 项：配置名称/验货方式(select)/抽检比例(input-number 0-100)/状态(radio)。默认 mode='全检'。无 v-permission。

## 差异
- 需补：独立子组件 addEditForm.vue(15+ 表单项)整体缺失(目标仅4项)；验货方式 0/2(按产品/按比例) 而非 EXAMINE_MODES 字符串；ratio v-if=type==='2' 条件显示 + 1-100 正整数校验；验货程度 degreeArr/验货图片保留 retain(1-12月)/需检验项 itemsArr(5项)/查验MadeInChina micArr/外箱查验 boxArr/产品查验 goodsArr(多组 checkbox/多选)；抽箱方式 pick(随机/指定)、6 组 true/false 单选；*Arr↔逗号串双向映射(show/submit)；表格列 验货方式 slot/验货程度 formatExamineType/抽箱方式 slot/是否验证尺寸 slot；权限键 lnspectionConfigAdd/lnspectionConfigQuery/lnspectionConfigUpdate/lnspectionConfigDel(注意拼写 lnspection)。
- 需删/确认：mode 枚举 EXAMINE_MODES、ratio 无条件显示的 input-number、status 开关、createTime。
- 字段映射：目标 mode vs 源 type(0/2)；目标 ratio(0-100 无条件) vs 源 ratio(仅按比例时,1-100正整数)；name 对应；其余十余项源字段目标全缺。
- 工作量：极大。
