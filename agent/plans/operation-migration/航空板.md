- 单页 head-info(航空板) + app-panel。左上"新增"，右上筛选。el-table + 分页。单个 el-dialog(900px, 内层 v-loading, footer 自定义在 div 内非 slot)。无体积单位下拉(umVolume 注释)，仅长度/重量单位。

## 筛选项

- 查询：v-permission="['aviationBoardQuery']" @click queryAll(1)。查询参数 params={page,size,model:{searchKey: name||undefined}}。无重置。

## 新增/编辑表单字段（label-width120, inline 各50%）
- 规格名称 prop=name el-input maxlength50 (ref firstInput)；required blur「规格名称不能为空」

- 长度单位 prop=umLength el-select(measurement_type) @change onLength；required change
- 重量单位 prop=umWeight el-select(weight_type)；required change（无体积单位下拉）
- 长度 prop=length el-input-number controls=false min0 max999999 precision2；required blur
- 宽度 prop=width min0 max999999 precision2；required blur
- 高度 prop=height min0 max999999 precision2；required blur
- 支持最大体积 prop=volume min0 max999999 precision2；required change「体积不能为空」

## 差异
- 需补：单位字典 umLength/umWeight + $fomatLength/$fomatWeight 过滤器列 + onLength 联动、尺寸字段 length/width/height/volume/loadLimit(min0 max999999 precision2)、英文名称 alias(中文校验)、查询参数 model.searchKey 包裹、权限键 aviationBoardAdd/aviationBoardQuery/aviationBoardUpdate/aviationBoardDel、新增 firstInput 聚焦。
- 需删/确认：编码 code、规格 spec(PLATE_SPECS)、maxWeight 单一重量字段(源为 loadLimit+umWeight)、status 开关、createTime。
- 字段映射：目标 maxWeight 对应源 loadLimit(+umWeight)；目标缺 alias/length/width/height/volume/umLength；name 对应。
- 工作量：极大。
