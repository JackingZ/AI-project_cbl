# 国际航线 operation-management/international-flight/index.vue → src/views/operation/InternationalFlight.vue

## 源页结构
- head-info「国际航线」+ app-panel；顶部「新增国际航线」文字按钮（无筛选区）；主表格 + 分页
- 弹窗1：新增/编辑国际航线（600px）
- 弹窗2：关联国家/地区（960px，el-transfer 穿梭框）

## 筛选项
- 无搜索栏，仅「新增国际航线」按钮。

## 表格列
- 航线类型 width=100，插槽 formatTypes(type)（0空运/1海运/2铁路/4卡航）
- 国际航线名称 width=300 prop=name show-overflow-tooltip
- 关联国家/地区 min-width=300 show-overflow-tooltip，:formatter=formatCountry（countries.countryName join ', '）
- 添加时间 width=170 prop=createTime
- 操作 width=130：编辑/删除

## 操作按钮
- 新增国际航线：v-permission="['addRoute']"
- 编辑：v-permission="['editRoute']"
- 删除：v-permission="['deleteRoute']"，$confirm「请确认是否删除该条数据?」/「温馨提示」

## 新增/编辑表单字段
form（label-width=120px，size=small）：
- 航线类型 prop=type：el-select，空运=0/海运=1/铁路=2/卡航=4。校验 required change「国际航线类型不能为空」
- 国际航线名称 prop=name：el-input maxlength=50。校验 required blur「国际航线名称不能为空」
- 关联国家/地区 prop=countryIds：只读 el-input(placeholder=`已选择(${countryIds.length})`) + append 搜索按钮打开穿梭框。校验 required change「请选择国家/地区」
- 备注 remark（非必填）：el-input maxlength=100
- 提交 saveFlight（组装 countries=[{countryId,countryName}]）

## 详情/次级弹窗/子页
- 关联国家/地区穿梭框：el-transfer（filterable，filter-method 按 name，titles ['关联国家/地区','已选择']，props key=id label=label），data=countryList

## 目标页现状
- SearchBar：航线名称(input)/航空公司(select AIRLINES)/状态(select)；列：航线名称/航班号/起飞港/到达港/航空公司/状态(switch)/创建时间；Modal：航线名称/航班号/起飞港/到达港/航空公司(select)/状态(radio)；rules name+airline required

## 差异
- 【结构性错配】源模型是「航线类型 + 名称 + 关联多国家 + 备注」；目标是「航班号/起飞港/到达港/航空公司」航班概念，字段全虚构。
- 需补列：航线类型(formatTypes)、关联国家/地区(formatCountry)、添加时间。
- 需补权限键：addRoute / editRoute / deleteRoute。
- 需补表单：航线类型 type(0/1/2/4)、关联国家 countryIds(穿梭框)、备注 remark。
- 需补：el-transfer 弹窗 + getCountryList + saveFlight 的 countries 组装；formatTypes 映射。
- 虚构需删：航空公司/AIRLINES、航班号、起飞港、到达港、状态 switch/radio、状态筛选、搜索栏。
- 字段映射：name→name 保留；其余无源对应。
- 工作量：大。
