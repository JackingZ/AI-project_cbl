# 区域配置 domestic-area/ → src/views/operation/DomesticArea.vue

## 源页结构
- index.vue 为 el-tabs（v-model activeName）容器，4 tab，均 v-if 惰性渲染子组件：
  - first "国内区域" → internal.vue
  - second "城市分区" → cities.vue
  - third "国家分区" → countries.vue
  - fourth "仓库分区" → warehouses.vue
- head-info title=区域配置。每子页 独立列表 + 新增/编辑弹窗 + 穿梭框选择弹窗。
- cities.vue 额外依赖自定义穿梭组件 zj-transfer.vue（州/省下拉 + 双列 checkbox 穿梭 + 左右搜索 + 全选/半选）。其余三页用原生 el-transfer。

## 筛选项（按子页）
- internal：区域名称 el-input + 查询 queryAll(1)。
- cities：国家 select(@focus getCountryList @change onCountryChange)→州/省 select(:disabled !countryId, @focus getStateList)→城市 select(:disabled !stateId, @focus getCityList) + 区域名称 + 查询。
- countries：区域名称 + 查询（无级联）。
- warehouses：国家 select(@focus getCountryList) + 区域名称 + 查询。

## 表格列（按子页）
- internal：区域名称(name,min120)/国家(countryName,min150)/区内省份(min250 tooltip, filterFunc(states) stateName join)/添加时间(createTime,width170,sortable)/操作(width130 fixed right)。
- cities：区域名称/国家/城市(min250 tooltip, filterFunc(result) cityName join)/添加时间(sortable)/操作。
- countries：区域名称/国家(min300 tooltip, filterFunc(result) countryName join)/添加时间(sortable)/操作。
- warehouses：区域名称/国家/fba仓库(min250 tooltip, filterFunc(result) warehouseName join)/添加时间(sortable)/操作。
- 四页高度 calc(100vh-350px)，分页 layout="total, prev, pager, next" size=10（服务端分页）。

## 操作按钮（权限键逐字）
- internal：新增 insideDomesticAdd；编辑 insideDomesticUpdate；删除 insideDomesticDel。
- cities：cityDomesticAdd / cityDomesticUpdate / cityDomesticDel。
- countries：countryDomesticAdd / countryDomesticUpdate / countryDomesticDel。
- warehouses：warehouseDomesticAdd / warehouseDomesticUpdate / warehouseDomesticDel。
- 删除均 $confirm('请确认是否删除该条数据?','温馨提示',warning) → deleteRegion/deleteAreaType。

## 新增/编辑表单字段（按子页）
- internal（600px）：区域名称 name(maxlength50 show-word-limit, required blur)；国家 countryId(select filterable, required change)；区内省份 area(只读 input placeholder=`已选择(${area.length})` + append 搜索 :disabled=!countryId 打开省份穿梭 el-transfer, required change)；备注 remark(maxlength100)。保存 saveRegion。
- cities（600px）：区域名称；国家 countryId(@change onCountryForm, required)；城市 area(只读 input + 搜索 handleCities 打开 ZjTransfer 弹窗 960px, required change)；备注。保存 confirmSave：diff 计算 insList/delList → saveAreaType({areaType:{...type:'1'}, delList, insList})。
- countries（600px）：区域名称；国家 area(只读 input + 搜索 handleCountry 打开 el-transfer, props {key:id,label:name}, required)；备注。保存 saveAreaType({...type:'2'})。
- warehouses（600px）：区域名称；国家 countryId(@change onCountry, required)；fba仓库 area(只读 input + 搜索 handleFba 打开 el-transfer, props {key:id,label:label}, label=`code-postal-stateName`, required)；备注。保存 saveAreaType({...type:'3'})。

## 详情/次级弹窗/子页
- zj-transfer.vue（cities 专用）：顶部 州/省 select(:disabled=!countryId, @change onStateChange)；左右两列自绘 checkbox（城市/已选择），各含搜索、全选/半选(indeterminate)、左右移动按钮。API getCityByState。方法 setData(countryId, list, stateList)/reset/rightData。
- 各子页穿梭弹窗关闭 itemDialogClose 会 clearQuery。

## 目标页现状
- 单一扁平 CRUD 表：无 tabs、无 4 子页、无穿梭。
- 筛选：区域名称 + 状态。列：name/code/province/status(switch)/createTime。表单：区域名称/区域编码/省份(input)/状态(radio)。仅 name 必填。

## 差异
- 需补：4-tab 容器 + 惰性渲染；internal/cities/countries/warehouses 四套列表+弹窗；国家→州→城市级联(cities)；原生 el-transfer 三处 + 自定义 ZjTransfer 组件；diff 式保存(insList/delList, type 1/2/3)；相关 API；12 个权限键；表格 filterFunc 聚合渲染。
- 需删/确认：status 列+toggle、province 列/字段、code 字段、状态筛选。
- 字段映射：name→各子页 name；源无单一 code/province（区域由子项集合定义 states/result）；createTime→createTime(源 sortable)。目标单表无法承载 4 类区域，需按 tab 拆分或重建。
- 工作量：极大（≈重建 4 页面 + 1 复杂穿梭组件）。
