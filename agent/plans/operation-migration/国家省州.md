# 地区管理 area-management/index.vue → src/views/operation/AreaManagement.vue

## 源页结构
- 左右分栏 flex。左侧 app-slide(width350, is-active) 可折叠侧滑（arrow-btn + toggle，箭头图 @/assets/imgs/arrow_left.png）。
- 左侧 el-tree(ref treeList, node-key id, :props treeProps, accordion, highlight-current, expand-on-click-node=false, default-expanded-keys=[0], empty-text 暂无数据) + 顶部关键字过滤输入框 + 搜索按钮(areaFilter)。
- 树懒加载多级行政区域，level 0→7：level0 根("全球")→getCountryByParent→getStateByCountry→getCityByState→getCountyByCity→getStreet(leaf)。loadNode 按 node.level 分支；filterNode 按 data.name.indexOf。
- 右侧 head-info title=地区管理 + 表格 + 分页（前端分页，tableData computed 切片，size=20）。
- 树节点字段：id/name/abbr/alias/level/countryId/parentId/stateId/cityId/children/leaf。treeProps {label:name, children:children, isLeaf:leaf}。
- 两弹窗：单条新增/编辑弹窗（"行政地区"600px）+ 批量新增弹窗（"批量新增行政区域"1000px）。均弹窗无跳转。

## 筛选项
- 树关键字：el-input v-model filterText size small placeholder 关键字；slot append el-button icon search @click areaFilter（前端过滤树节点）。
- 右侧搜索：el-input v-model search placeholder="地区代码/地区名称/地区简称/英文名称" clearable size small width280；无按钮，computed resultData 实时前端过滤(abbr/alias/id/name indexOf)。

## 表格列
- 地区代码 width150 → row.id
- 地区名称 min-width230 → row.name
- 地区简称 min-width180 → row.abbr
- 英文名称 min-width230 → row.alias
- 操作 width150：编辑/删除
- 表格高度 calc(100vh-295px) border。分页 layout="total, prev, pager, next"。

## 操作按钮
- 新增：v-permission="['countryStateAdd']" type=text icon=circle-plus-outline，:disabled="!isAddBtnShow"(当前节点存在且 level!==7)，@click add。
- 批量新增：type=text(无权限键)，:disabled="!isAddBtnShow"，@click addBatch。
- 编辑：v-permission="['countryStateUpdate']"。
- 删除：v-permission="['countryStateDel']"，$confirm('删除将无法恢复，是否继续？','温馨提示',warning) → deleteContainer(id, level)。

## 新增/编辑表单字段（单条弹窗 "行政地区"）
- 地区代码 prop=id：el-input，:disabled=isEdit，maxlength30 show-word-limit。required blur「地区代码不能为空」+ validator 禁中文(/[一-龥]/)。
- 地区名称 prop=name：el-input maxlength50。required blur「地区名称不能为空」。
- 地区简称 prop=abbr：el-input maxlength10。required blur「地区简称不能为空」。
- 英文名称 prop=alias：el-input maxlength50。required blur + validator 禁中文。
- 保存 saveConfirm：编辑→updateArea，新增→addArea（自动计算 parentId/countryId/level=currentNode.level+1）。

## 详情/次级弹窗/子页（批量新增弹窗 1000px）
- 顶部查询：国家下拉(batchForm.countryId，硬编码 美国=US/加拿大=CA) + 只读 currentName("添加到{当前节点}下级") + 英文名称输入 batchForm.name + 查询 getBatchAreaName（校验国家/英文名非空→getCityName→填 batchData）。
- 批量表格(height500 可编辑行)：地区名称(input name)/地区简称(input abbr)/英文名称(input alias)/操作(删除行 deleteBatch)。
- 确定 confirmBatch：校验每行 abbr/alias/name 完整 → addBatchCity({countryId, level, parentId, list})。

## 目标页现状
- SearchBar(名称/层级 AREA_LEVELS/状态) + ProTable + Modal 通用 CRUD。无树、无侧滑、无懒加载、无批量弹窗。
- 列：name/code/level/alias/status(el-switch)/createTime。
- 表单：名称/区域编码/层级(select)/英文名称/状态(radio)。仅 name 必填。status 启用/禁用为源无概念。

## 差异
- 需补：左侧行政区域懒加载树 + 侧滑折叠；树 7 级联动 API；前端过滤(filterText 树 + search 表格)；单条弹窗 id/name/abbr/alias 及中文校验/编辑禁改 id；批量新增弹窗(国家下拉/currentName/getCityName/可编辑表格/addBatchCity)；权限键 countryStateAdd/Update/Del；新增按钮 disabled 依赖 level!==7。
- 需删/确认：层级下拉筛选、状态筛选、status 列与 toggle、code 字段、layout size 切换。
- 字段映射：name→name；alias→alias；code→id(地区代码)；源 abbr(地区简称)目标缺；level 为数字 0-7 非文本枚举。
- 工作量：极大（树懒加载联动 + 批量弹窗为核心）。
