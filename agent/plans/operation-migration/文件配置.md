# 文件配置 file-config/ → src/views/operation/FileConfig.vue

## 源页结构
- head-info title=文件配置；单页列表 + 分页；新增/编辑弹窗在子组件 addModel.vue(<add-model ref @load="loadData"/>)。无 tab/侧滑；弹窗 600px。

## 筛选项
- 新增文件：el-button type=text v-permission="['fileConfigAdd']"(float left) @click addFile。
- 所属模块 el-select moduleCode focus getModeList @change handleModeChange(清空 typeCode+filetypeList)，label=moduleName value=id。
- 文件类别 el-select typeCode :disabled="!moduleCode" focus getTypeList label=fileType。
- 国家 el-select countryCode :filter-method="filterCountry" focus getCountryList @change handleCountryChange(reload) label=newName(name-alias)。
- 文件名称 el-input fileName slot prepend "文件名称" maxlength20 clearable width250。
- 查询：v-permission="['fileConfigQuery']" @click loadData(1)。

## 表格列
- moduleName 所属模块 width140
- fileType 文件类别 width140
- countryName 国家名称 min120
- fileName 文件名称 min120
- fileDesc 文件描述 width120
- fileExt 文件类型 width140：fileExtList 映射(excel1/word2/pdf3/text4/图片5/其他6)
- 是否必要 ifNeed width120：0否/1是
- 是否审核 ifAudit width120：0否/1是
- createTime 添加时间 width180
- 操作 width100 fixed right

## 操作按钮
- 编辑：v-permission="['fileConfigUpdate']" @click editFile(→addModel.show(row))。
- 删除：v-permission="['fileConfigDel']" @click deleteFile($confirm "请确认是否删除该条数据?")。

## 新增/编辑表单字段（addModel.vue, 600px, label-width100）
- countryCode 国家 select filter-method/focus，:disabled=isEdit；required change「请选择国家」
- moduleCode 所属模块 select :disabled=isEdit @change modeChange(清空 typeCode)；required change「请选择所属模块」
- typeCode 文件类别 select :disabled=isEdit focus getTypeList；required change「请选择文件类别」
- dictId 文件名称 select :disabled=isEdit focus getFileNameList @change handleChange(带出 fileDesc/fileName)；required change「请输入文件名称」
- fileDesc 文件描述 textarea v-if="false"(隐藏,disabled)
- fileExt 文件类型 select(fileExtList)；required change「请选择文件类型」
- ifNeed 是否必要 radio(0否/1是)；required change「请选择是否必要」
- ifAudit 是否审核 radio(0否/1是)；required change「请选择是否审核」
- 提交时补 moduleName/fileType(由所选 id 反查)。

## 目标页现状
- 通用 CRUD：筛选 name(文件名称)/type(文件类型)/status；列 name/type/path(存储路径)/status/createTime；Modal name/type(select)/path/status。无级联模块/类别、无国家、无 ifNeed/ifAudit、无权限键、无 edit 禁用。

## 差异
- 需补：所属模块→文件类别级联(disabled 依赖+change 重置)、国家 filter-method 检索、文件名称 prepend、fileConfigAdd/fileConfigQuery 权限键；表格 moduleName/fileType/countryName/fileDesc/fileExt(映射)/是否必要/是否审核 列、编辑/删除权限键；addModel 子组件弹窗 8 字段(edit 时前四项 disabled、dictId 带出描述、fileExt 映射、两组 radio)，全部 required。
- 需删：目标 path(存储路径) 字段源无对应。
- 字段映射：目标 name→源 fileName；目标 type→源 fileExt/typeCode(语义不同,需拆分)。
- 工作量：大。
