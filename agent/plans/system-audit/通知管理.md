# 通知管理一致性核对（源 workProject2-jht Vue2 → 目标 Vue3）

- 源：`agent/workProject2-jht/src/views/system-management/notice-manage/index.vue`（通知项 × 客户类型 关联服务 + 通知模版）
- 目标：`src/views/system/NoticeManage.vue`（单文件通用 CRUD，mock=`noticeMngApi`，字段虚构）

> 背景约定：跳转改弹窗、custType 简化可标注。**核心结论：源是"通知类型/通知项 × 四类客户(聚货通/供应商/代理商/客户)勾选启用 + 关联服务穿梭框 + 通知模版编辑"的配置页；目标虚构成"通知标题/类型/发布人/状态"的列表 CRUD，形态错配。**

---

## 1. 筛选项
- 源：**无筛选**（全量表格 page=1,size=999）。
- 目标：通知标题 name、类型 type(系统/公告)、状态 status、新增按钮。

| 判定 | 项 |
|---|---|
| 目标有源无=错配 | 全部筛选项 + 新增按钮 | 源无搜索区、无新增 |

## 2. 表格列
- 源列：通知类型 msgType、通知项 msgSubType(overflow-tooltip)、**关联服务勾选区**(一列内含四组：聚货通 isJuCheck / 供应商 isGoCheck / 代理商 isDaiCheck / 客户 isKeCheck，各含"服务(n)"按钮打开穿梭框)、通知模版(按钮列打开模板弹窗)。
- 目标列：通知标题 name、类型 type、发布人 publisher、状态 status(switch)、创建时间。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **通知类型 msgType + 通知项 msgSubType** |
| 源有目标无=需补 | **四类客户关联勾选**(聚货通/供应商/代理商/客户 复选 + 各"服务(n)"按钮) |
| 源有目标无=需补 | **通知模版列**(按钮打开模板编辑弹窗) |
| 目标有源无=错配 | 通知标题 name、发布人 publisher、状态 status | 源无此三字段，虚构 |
| 字段差异=错配 | 类型：源=业务通知类型；目标=系统/公告 |

## 3. 弹窗/表单字段
- 源两个弹窗：
  - **通知模版弹窗**(editRow)：模板标题 templateTitle(≤20)、模板内容 templateContent(textarea)。均必填。
  - **关联服务弹窗**(onSign)：`el-transfer` 穿梭框(服务/已选择，可搜索)，按客户类型(custType 0聚货通/1客户/2代理商/3供应商)拉取 serviceList，保存 updateManage。
- 目标 Modal：通知标题 name、类型 type、发布人 publisher、状态 status。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **通知模版编辑弹窗**(templateTitle + templateContent) |
| 源有目标无=需补 | **关联服务穿梭框弹窗**(按客户类型选服务) |
| 目标有源无=错配 | 通知标题/类型/发布人/状态 表单 |
| 设计简化 | 四类客户 custType(0/1/2/3) 为 SaaS 多租户特性，单角色可简化，但**通知项配置本身**不应错配为标题 CRUD |

## 4. 操作按钮 + v-permission
- 源：勾选启用四类客户 checkChange(直接 updateManage)、"服务(n)"打开穿梭框 onSign、"通知模版"打开模板弹窗 editRow。**源本页无 v-permission 权限键**。
- 目标：新增/编辑/删除 + 状态 switch。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **四类客户勾选启用、关联服务、通知模版编辑** |
| 目标有源无=错配 | 新增/删除 CRUD |
| 权限 | 源本页无 v-permission；目标 0 接入 |

## 5. 子组件
无独立子文件（弹窗内联于 index.vue）。目标未实现两弹窗。

## 一致性评分：通知管理 **15 / 100**
严重错配页。源为"通知类型/通知项 × 四类客户关联服务(穿梭框) + 通知模版编辑"的配置页，目标虚构成"通知标题/发布人/状态"通用列表 CRUD。核心的通知项、四客户勾选、关联服务穿梭框、模版编辑全缺。需整页按源业务重写（客户类型维度可按单角色酌情简化，但通知项+模版+关联服务结构须保留）。

## 建议 can 动作
源本页无权限键。若接入：`can('editTemplate')` 编辑模版、`can('editService')` 关联服务、`can('enable')` 勾选启用。不建议标准 add/del。
