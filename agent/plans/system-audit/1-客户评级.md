# 客户评级 CustomerLevel 一致性核对

- 源：`agent/workProject2-jht/src/views/system-management/customer-level/index.vue`（Vue2 + class 组件）
- 目标：`src/views/system/CustomerLevel.vue`（Vue3 setup + 通用 CRUD 骨架）
- 源权限键：`addCustomerLevel` / `editCustomerLevel` / `deleteCustomerLevel`；路由 role `customerLevel`
- 一致性评分：**中等差异**（本页是 6 页里最接近的，字段基本对得上，但仍有虚构列）

## 结论速览
源是一个「无筛选、纯列表 + 新增/编辑/删除弹窗」的额度评级配置页。目标套用了带筛选/状态开关的通用骨架，**引入了源不存在的筛选项、状态列、状态开关、创建时间列**，并把源的核心业务字段「额度金额 rating」丢失。

## 筛选项
| 项 | 源 | 目标 | 结论 |
|----|----|----|----|
| 等级名称 name 输入 | 无（源无任何筛选区）| 有 | 【目标多余/占位】源整页无搜索栏 |
| 状态 select | 无 | 有 STATUS_OPTIONS | 【目标多余/虚构】源无启用/禁用概念 |

| 列 | 源 prop | 目标 prop | 结论 |

| 额度金额 | `rating`（`￥{{rating}}`）| 无 | 【源有目标无=需补】核心业务字段缺失，目标用无关的 `score 评分` 替代 |
| 备注 | `remark` | 无 | 【源有目标无=需补】 |

| 创建时间 createTime | 无 | 有 | 【目标多余/虚构】源列表无此列 |

源无独立详情弹窗（编辑弹窗即回填）。目标同。一致。

## 子组件
无。两侧均单文件。

## 建议 can 动作
- can add（源 addCustomerLevel）
- can edit（源 editCustomerLevel）
- can del（源 deleteCustomerLevel）
- 无 can toggle（源无此动作，目标状态开关属虚构）

## 需补要点（真实业务缺漏）
1. 「额度金额 rating」列 + 表单项（￥金额，精度2）——评级页的核心语义，目标误换成 score/discount。
2. 「备注 remark」列 + 表单项。
3. code 编辑态锁定 + maxlength 限制（5/30）。
4. 移除虚构的 状态列/状态开关/创建时间/筛选区（若要严格保真）。
