# 司机管理一致性核对（源 workProject2-jht Vue2 → 目标 Vue3）

- 源：`agent/workProject2-jht/src/views/system-management/chauffeur-management/index.vue` + `components/addEditForm.vue`
- 目标：`src/views/system/ChauffeurManagement.vue`（单文件通用 CRUD，mock=`driverApi`，字段虚构）

> 背景约定：单角色无 custType、所属公司下拉、供应商联动为 SaaS 特性，标【设计简化】。**核心结论：目标是模板通用 CRUD 骨架，虚构了"准驾类型 A2/B2/C1 + 驾驶证号"，与源真实司机档案字段严重错配。**

---

## 1. 筛选项
- 源：所属公司 custId【设计简化】、启用状态 status(禁用/启用)、司机姓名 name。
- 目标：司机姓名 name、准驾类型 type(A2/B2/C1)、状态 status。

| 判定 | 项 | 说明 |
|---|---|---|
| 目标有源无=错配 | 准驾类型 type | 源无"准驾类型"概念，虚构字段 |
| 一致 | 姓名、状态 | 语义对齐 |

## 2. 表格列
- 源列：司机姓名 name、证件号码(certType 格式化"身份证\|号码")、联系手机 phone、电子邮箱 email、所在地区(state/city/county 拼接)、驾照日期 expire(YYYY-MM-DD)、所属公司 custName、启用状态(switch，权限 `driverChangeStatus`，切换带 `$confirm` 确认)、操作。
- 目标列：司机姓名 name、联系电话 phone、驾驶证号 license、准驾类型 type、状态 status、创建时间。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **证件号码 certNo + 证件类型 certType**(身份证/护照/港澳通行证/其他 格式化展示) |
| 源有目标无=需补 | **电子邮箱 email** |
| 源有目标无=需补 | **所在地区**(州/省 city/county 拼接) |
| 源有目标无=需补 | **驾照日期 expire** |
| 目标有源无=错配 | 驾驶证号 license、准驾类型 type | 源无此二字段，虚构 |
| 字段差异 | 状态 switch：源带确认弹窗+权限 `driverChangeStatus`；目标直接切换无确认无权限 |
| 设计简化 | 所属公司 custName 列 |

- 源新增/编辑字段：所属公司 custId、州/省 stateId、城市 cityId、区/县 countyId(三级联动)、关联用户 userId、关联车辆 vehicleId、是否接受加班 overtime、是否接受长途 distance、司机姓名 name、证件号码 certNo(+certType 前置下拉，身份证走正则校验)、联系手机 phone(禁中文)、电子邮箱 email(邮箱校验)、驾照日期 expire、**驾照照片 photo(上传+预览+删除，必填 2MB)**。
- 目标表单：司机姓名 name、联系电话 phone、驾驶证号 license、准驾类型 type、状态 status。

| 判定 | 项 |

| 源有目标无=需补 | **电子邮箱 email**(格式校验) |

## 4. 操作按钮 + v-permission
源逐字权限键：新增司机 `addDriver`、查询 `queryDriver`、编辑 `editDriver`、删除 `deleteDriver`、状态切换 `driverChangeStatus`(`$checkPermission`)。
目标：0 权限接入，仅通用文案"新增/编辑/删除"。

| 判定 | 项 |
|---|---|
| 需补(权限) | 5 个权限键全未接入，无 usePagePerms/can |
| 字段差异 | 源新增/编辑走独立大弹窗子组件；目标简化为通用 Modal |
