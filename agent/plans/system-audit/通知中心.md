# 通知中心一致性核对（源 workProject2-jht Vue2 → 目标 Vue3）

- 源：`agent/workProject2-jht/src/views/system-management/notice-center/index.vue`（消息收件箱）
- 目标：`src/views/system/NoticeCenter.vue`（单文件通用 CRUD，mock=`noticeCtrApi`，字段虚构）

> 背景约定：跳转改弹窗、占位筛选可标注。**核心结论：源是"消息收件箱"（按通知类型 radio 分组 + 全部/未读/已读 计数 tab + 批量标记已读 + 多选表格），目标虚构成"通知标题/类型/状态"的可增删改 CRUD，形态错配。收件箱不应有新增/编辑/删除。**

---

## 1. 筛选/顶部
- 源：通知类型 radio-button 组(noticeList，全部通知+各类型)、关键词 keyWord(带搜索按钮)、右上角"通知配置"跳转按钮、下方"全部/未读/已读"计数 tab(numberList)、消息子类型下拉(表头内 typeId)。
- 目标：标题 name、类型 type(NOTICE_TYPES)、状态 read(未读/已读)、新增按钮。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **通知类型 radio-button 分组切换** |
| 源有目标无=需补 | **全部/未读/已读 计数 tab**(带数量) |
| 源有目标无=需补 | **消息子类型下拉**(表头内联) |
| 源有目标无=需补 | **"通知配置"跳转入口**(源 `$router.push('/system/notice-config')`) |
| 目标有源无=错配 | 新增按钮 | 收件箱不应新增 |
| 字段差异 | 状态：源 全部/未读/已读 tab；目标 下拉筛选 |

## 2. 表格列
- 源列：多选(type=selection)、消息标题 msgTitle(未读/已读图标)、消息内容 msgContent(点击 onInfo 弹窗查看并标记已读)、接收时间 receiveTime、消息类型 msgType、消息子类型 msgSubtype(表头内联子类型下拉)。
- 目标列：标题 name、类型 type、状态 read(tag)、时间 date、创建时间；操作(编辑/删除)。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **多选列**(批量标记已读用) |
| 源有目标无=需补 | **消息内容 msgContent** 列 + 点击查看弹窗 |
| 源有目标无=需补 | **接收时间 receiveTime、消息子类型 msgSubtype** |
| 源有目标无=需补 | **未读/已读图标**(msgTitle 前) |
| 目标有源无=错配 | 编辑、删除 操作按钮 | 收件箱无编辑/删除 |
| 字段差异 | 状态展示：源图标+tab；目标 tag 列 |

## 3. 表单字段
- 源：无新增/编辑表单；仅点击内容 onInfo 弹只读消息+自动标记已读。
- 目标 Modal：标题 name、类型 type、状态 read。

| 判定 | 项 |
|---|---|
| 目标有源无=错配 | 整个新增/编辑弹窗（源为只读收件箱，不应有编辑表单） |
| 源有目标无=需补 | **消息详情只读弹窗**(onInfo，$confirm 展示内容并标记已读) |

## 4. 操作/按钮
- 源核心操作：**标记为已读**(选中批量 onSign)、**全部标为已读**(onAllSign)、点击内容查看(onInfo 标记已读)、通知配置跳转。**无 v-permission**（收件箱个人消息，源未加权限键）。
- 目标：新增/编辑/删除通用 CRUD。

| 判定 | 项 |
|---|---|
| 源有目标无=需补 | **标记为已读 / 全部标为已读** 批量操作 |
| 源有目标无=需补 | **通知配置跳转** |
| 目标有源无=错配 | 新增/编辑/删除 |
| 权限 | 源本页无 v-permission；目标亦 0 接入。此页权限可弱化 |

## 一致性评分：通知中心 **20 / 100**
严重形态错配。源为"消息收件箱"(类型分组+未读计数 tab+批量标记已读+内容详情弹窗)，目标虚构成标题/类型/状态可增删改的 CRUD。收件箱核心的"标记已读/批量已读/子类型筛选/计数 tab"全缺，且多出不应存在的新增/编辑/删除。需整页按收件箱语义重写。

## 建议 can 动作
本页源无权限键（个人消息中心）。若需接入：`can('read')` 标记已读。不建议 add/edit/del。
