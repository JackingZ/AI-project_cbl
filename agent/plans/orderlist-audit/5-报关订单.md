# 报关订单 一致性审计

源: `agent/workProject2-jht/src/views/orderlist-management/customs-order/index.vue` (+ detail.vue / info.vue)
目标: `src/views/orderlist/CustomsOrder.vue`
路由: `/orderlist/customs-order` (name `OlCustoms`)

## 关键结构差异（源为"按订单/按柜"双模式）

源顶部有 radio-group `按订单(1)/按柜(2)`(custType 0/3 显示)，两种模式各有独立筛选区+表格：
- 按订单：报关单主表格
- 按柜：柜/提单维度表格（供应商/起运国/目的国/柜号提单号 等）

**目标只实现了"按订单"模式，完全没有"按柜"模式的 radio 切换、按柜筛选区、按柜表格。** 属较大简化——需标注：报关订单缺失"按柜"视图（radio 切换 + 按柜筛选[供应商/起运国/目的国/进出口/报关状态/报检状态/柜号提单号] + 按柜表格[柜号提单号/进出口/供应商/起运国/目的国/报关状态/报检状态/起运时间/到港时间/查看]）。

## 筛选项比对（按订单模式）

源：订单类型(销售/采购,custType0/2)、公司类型、所属公司、订单状态(新建/报关放行/报关查验/退运)、订单类别(报关/报检/报关&报检 id1/2/3)、报关类型(普通报关/出口退税/整柜买单 id0/1/2)、服务国家、下单时间、关键字(前置 订舱单SO/柜号/原单号)、查询。

目标：订单类型(ORDER_TYPES)、订单状态(ORDER_STATUS)、报关类型(DECLARE_TYPES 进口报关/出口报关/转关)、关键字(前置 订舱单SO/柜号/原单号 soCode/containerNo/code)、更多展开：公司类型、所属公司、订单类别(IO_TYPES 进口/出口)、服务国家、下单时间。

| 项 | 源 | 目标 | 结论 |
|---|---|---|---|
| 订单类型 | 销售/采购 | ORDER_TYPES(销售/采购) | 一致 |
| 公司类型/所属公司 | select | 更多内占位 | 一致 |
| 订单状态 | 新建/报关放行/报关查验/退运 | ORDER_STATUS(待处理/处理中/已完成/已取消) | **差异**：源订单状态枚举是 新建/报关放行/报关查验/退运；目标套通用 ORDER_STATUS，语义不符。建议改 ['新建','报关放行','报关查验','退运'] |
| 订单类别 | 报关/报检/报关&报检 | **目标错位**：更多内"订单类别"绑到了 IO_TYPES(进口/出口) | **差异**：源"订单类别"应是 报关/报检/报关&报检；目标把它做成了进出口。且源另有独立"报关类型"下拉。建议：订单类别改 ['报关','报检','报关&报检'] |
| 报关类型 | 普通报关/出口退税/整柜买单 | DECLARE_TYPES(进口报关/出口报关/转关) | **差异**：源报关类型是 普通报关/出口退税/整柜买单；目标用了另一套 DECLARE_TYPES。建议改 ['普通报关','出口退税','整柜买单'] |
| 进出口类型 | 源按订单模式无此筛选(仅"按柜"有) | 目标用"订单类别"位置放了进出口 | 见上，属错位 |
| 服务国家 | select 远程 | 更多内占位 | 一致 |
| 下单时间 | daterange | 更多内 daterange | 一致 |
| 关键字前置 | 订舱单SO/柜号/原单号 | 同(soCode/containerNo/code) | 一致 |

| 列 | 结论 |
|---|---|
| 全部列 | **完整覆盖**，顺序与源一致 |

## 详情弹窗字段

源 detail.vue(按订单)/info.vue(按柜)深层未逐字段核。目标通用 OrderDetailDialog 的"报关"业务类型专属块含：报关单号、进出口、报关状态、报检状态、起运国、柜号/提单——覆盖报关订单核心字段，良好。

## 权限键接入缺口（重点）

目标未接入 usePagePerms。建议 basePath `/orderlist/customs-order`：
- `can('view')` → 查看
- `can('assign')` → 指定供应商（源 supplierAuthority）
- `can('declareStatus')` → 报关状态修改（源 draftAuthority，若后续补状态操作）
- `can('inspectStatus')` → 报检状态修改（源 inspectionAuthority，可选）
- `can('auditFile')` → 文件审核（源 customAuditFile，可选）

建议 can 动作集：**view, assign**（declareStatus/inspectStatus/auditFile 视是否补状态操作）

## 评分：大缺漏

主要缺漏：①完全缺失"按订单/按柜"radio 双模式——整个"按柜"视图(筛选+表格)未实现；②筛选枚举多处语义错位（订单状态、订单类别错绑进出口、报关类型均套错通用常量）；③文件状态/报关状态/报检状态的可操作入口(文件审核/改状态)全部降级为纯文本；④权限键 0 接入。⑤目标多了源没有的"取消"操作。
