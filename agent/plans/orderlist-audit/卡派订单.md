## 四、详情弹窗字段（源 detail.vue vs 目标 OrderDetailDialog 卡派分支）

源 detail 分组：基础信息(下单客户/装货地址/目的地/付款方式/取货时间/备注)、发货人(发货人/电话/地址/邮编/详细地址)、收货人(收货人/电话/地址/邮编/详细地址)、货物信息(拼箱整柜/车型柜型/总件数/总货值/总重量/总体积/物流总运费/附加服务费/关税费用/附加关税)。

目标 OrderDetailDialog 卡派分支仅：货物/提货日期/送货日期/司机/车牌 + 通用基础信息(订单号/原单号/业务类型/客户名称/下单客户/目的国/状态/审核/件数/箱数/重量/体积/金额/供应商/下单时间/截止付款)。

结论：详情大幅简化。**缺漏（如需保真需补）**：发货人区块(consignor/phone/address/zip)、收货人区块(harvestMan/phone/address/zip)、装货地址、付款方式、拼箱整柜、总货值、物流总运费/附加服务费/关税/附加关税。按"跳转统一改弹窗+通用详情弹窗"简化策略可接受，标注为简化。

## 五、权限键接入（当前 0 接入 usePagePerms）

源权限键：`kapieOrderQuery`(查询)、`kapieOrderGet`(查看)、`assignVehicles`(分配车辆,注释)；司机信息无键。

建议 CarOrder 接入 can：
- `can('query')` → 查询按钮（对齐 kapieOrderQuery）
- `can('view')` → 查看（对齐 kapieOrderGet）
- `can('assign')` → 分配车辆（对齐 assignVehicles）
- 司机信息源无权限键，可不接或用 `can('view')`

列完整、操作齐、跳转按约定弹窗化。扣分：业务类型/服务/时间从常显折进"更多筛选"，与源常显不一致；详情字段大幅缩减；0 权限键接入；订单状态值域与源 8 值不符。
