# 仓库订单 一致性审计

源: `agent/workProject2-jht/src/views/orderlist-management/warehouse-order/index.vue`
目标: `src/views/orderlist/WarehouseOrder.vue`
路由: `/orderlist/warehouse-order` (name `OlWarehouse`)

> 背景约定：新项目单角色、无 custType 多租户；跳转统一改弹窗（录单/调度除外）；无数据依赖的筛选做静态占位；深操作(打印/导出/下载标签)走 demoAction。以下仅标注真实缺漏。

## 关键结构差异（源有双表格模式）

源页面按 `业务类型` 分两套表格：
- `type !== '3'`（仓储/散收拼货）：主表格，操作列=查看/删除/账单信息/更多(下载标签)
- `type === '3'`（拆柜打托）：独立表格，列不同（多"订单号+原单号"两列、装货方式文案不同），操作列=查看 / **生成拆柜** / 账单信息

目标只做了单表格，把两套的列和按钮合并近似呈现。属刻意简化，但**生成拆柜按钮**（源在拆柜打托表格里，`openTankTask !== 1` 且有 `addRemoval` 权限时显示）目标塞进了"更多"下拉里当 demo 项——功能对齐可接受，标注即可。

## 操作按钮比对

- 查看 `v-permission="['warehouseOrderGet']"`

目标操作：查看 / 删除 / 账单信息 / 流转订单(demo) / 更多下拉(生成拆柜 + 4个下载标签 demo)

| 按钮 | 源权限键 | 目标 | 结论 |

## 详情弹窗字段

源 detail.vue/detail2.vue 未逐字段核（属深层页面）。目标用通用 OrderDetailDialog（基础信息14项+业务类型专属块）。仓库订单核心字段(原单号/业务类型/客户/仓库/箱数/体积/重量/备注)基本覆盖。**下单仓库、装货方式**在通用弹窗中无对应项，属小缺漏，可接受。

## 权限键接入缺口（重点）

目标当前**未接入 usePagePerms**。建议 `const { can } = usePagePerms()`，basePath 用路由 `/orderlist/warehouse-order`，接入：
- `can('view')` → 查看按钮 :disabled
- `can('del')` → 删除按钮 :disabled
- `can('bill')` → 账单信息按钮（对应源 warehouseOrderFinancial）
- `can('export')` → 导出当前数据（可选，深操作）

建议 can 动作集：**view, del, bill**（export/print 可选）
