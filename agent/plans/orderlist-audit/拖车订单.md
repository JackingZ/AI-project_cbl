## 四、详情弹窗字段（源 detail.vue vs 目标 OrderDetailDialog 拖车分支）

源 detail：拖车类型/卸货方式(进口)/付款方式/起运港/取货时间/入仓号/入仓时间(进口)/还柜地址/补料时间(出口)…完整分类字段。
目标拖车分支：SO号/拖车类型/进仓时间/取货时间 + 通用基础信息。

结论：详情简化。缺漏（保真需补）：卸货方式、付款方式、入仓号、还柜地址、补料时间等按类型(进口/出口)区分的字段。按弹窗简化可接受，标注。

## 五、权限键接入（当前 0 接入）

源键：`trailerOrderQuery`(查询)、`trailerOrderView`(查看)、`trailerOrderSupperier`(指定供应商)、`trailerOrderVehicle`(分配车辆)、`trailerOrderFinancial`(账单)。

建议 TrailerOrder 接入 can：
- `can('query')` → 查询（trailerOrderQuery）
- `can('view')` → 查看（trailerOrderView）
- `can('assign')` → 指定供应商（trailerOrderSupperier）
- `can('vehicle')` → 分配车辆（trailerOrderVehicle）
- `can('bill')` → 账单信息（trailerOrderFinancial）
- 取消若保留可 `can('cancel')`（源无对应键）
